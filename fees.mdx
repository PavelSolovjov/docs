# TON and jettons: transfers

### What makes up the fee

The fee for sending [TON](https://ton.org) or jetton transactions on the [TON network](https://ton.org) is estimated locally in the application based on the current network configuration (config) and message parameters. The calculation includes:

- **Storage:** fee for using contract cells; depends on data volume and network rates.
- **Import message:** fee for processing incoming external message that the user initiates the transaction with.
- **Gas:** fee for code execution; depends on the number of outgoing messages (1 message — less gas, several — more; the code uses fixed gas values for 1–4 messages).
- **Forward fees:** fee for delivering each outgoing message across the network.

The total amount is shown in nano-TON and displayed to the user before confirmation as **"Network fee"** (blockchain fee) in TON. The exact amount may slightly differ from what is actually charged by the network after the transaction is included in a block.

### Who pays

The fee is always paid by the sender in TON. Without sufficient TON balance in the account, neither TON nor jettons can be sent (exception — gasless scenario for supported jettons, see below).

### Where it's shown

Before sending a transfer (TON or jetton), the preview screen displays a line with the fee in TON and, if necessary, the fiat equivalent. For simple transfers, a "Network fee" block is used with a brief description (and a "more details" button, if available).

# Gasless

**Gasless** — the ability to pay the fee for jetton transfer in the token itself (for example, in [USDT](https://tether.to)), rather than in TON. The TON fee is paid for the user by a **relayer** ([Tonhub](https://tonhub.com) service); the equivalent is deducted from the user in the transferred token.

## When available

- Supported only for **specific jettons** (list is set by backend config: `gas_jettons`).
- Available only for **W5** wallet (v5R1); gasless is not offered for other wallet versions.
- Configuration (token list and relayer address) is requested from [Tonhub API](https://tonhub.com): `gasless/mainnet` or `gasless/testnet` → `config`. The config specifies `relay_address` and `gas_jettons` array (master_id).

## How gasless fee is calculated

Before sending, the application requests a gasless estimate: request to `gasless/.../estimate` with parameters (wallet address, public key, messages in BOC format). The response includes:

- **relay_address** — relayer address;
- **commission** — fee (deducted from user in token);
- **from** — address from which it will be debited;
- **valid_until** — until what time the estimate is valid;
- **messages** — final messages (including fee consideration).

The user sees how much token will be debited (transfer amount + fee) and can choose: pay fee in TON or in token (gasless). If gasless is selected, the application sends the signed transaction to the backend (`gasless/.../send`); the relayer sends it to the network and pays gas in TON.

## Limitations and errors

- **Cooldown:** a pause (several minutes) may be required between gasless transfers; otherwise the user is asked to wait or pay the fee in TON.
- **Insufficient funds:** if the transfer amount including fee in token exceeds the balance, gasless is unavailable — need to reduce the amount or pay in TON.
- **Try later / Not enough:** in case of estimation or sending errors, the user sees "Try later" or "Insufficient funds" message and can switch to paying fee in TON if necessary.

# SOL and SPL tokens: transfers

The fee for sending [SOL](https://solana.com) or [SPL tokens](https://spl.solana.com) on the [Solana network](https://solana.com) is **not calculated in the application**. It is requested from the [Tonhub](https://tonhub.com) backend: POST to `/solana/transaction/fees/mainnet` (or `devnet`) with body `{ transaction }` (serialized transaction). The response contains an object with a value field — the fee (displayed to the user in SOL and, if necessary, in fiat equivalent).\
The fee is paid by the sender in SOL. Without sufficient SOL balance, the transaction will not be signed/sent.

### Where it's shown

In the [Solana](https://solana.com) transfer preview screen, a "Network fee" (blockchain fee) block is displayed with the amount in SOL and fiat (if exchange rate is available).

# Staking fees

When participating in [TON staking](https://ton.org/stake), users encounter several types of fees that are set individually by each pool. All fees are clearly displayed in the staking interface before performing operations.

- Deposit fee - the fee for sending funds is 0.2 TON.
- Withdrawal fee - the fee for withdrawing funds ranges from 0.2 to 0.4 TON.

# Token exchange fees

[Tonhub](https://tonhub.com) offers two cryptocurrency exchange options:

- [Dedust.io](http://Dedust.io) - decentralized partner exchange. Users pay only the standard exchange fee, no additional charges.
- [Changelly](https://changelly.com) - partner exchange service. Only the standard service fee is charged, without additional payments.
