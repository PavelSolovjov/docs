# Пополнение

Для использования основных возможностей сервиса пользователю необходимо пополнить свой [смарт-контракт](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02), который выступает в роли банковского счета. К смарт-контракту привязываются [банковские карты](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FE5D3DLM) пользователя для осуществления платежей. При оплате банковской картой средства списываются со счета пользователя, к которому прикреплена данная карта.\
В Holders существует два типа контрактов:

1. Контракты поддержываемых валют - для каждого блокчейна и каждой криптовалюты в Holders разворачивается отдельный смарт‑контракт. В настоящее время функционируют три основных контракта:
   1. [TON ](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09U0DBTKBN)— смарт‑контракт для [блокчейна TON](https://ton.org/).
   2. [USDT](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09U0DBTKBN) — смарт‑контракт для токена [USDT](https://tether.to/en/) ([на базе TON](https://ton.org/)) — доступен только для существующих пользователей (новые открытия недоступны).
   3. [USDC](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09TQEHHDJ7) — смарт‑контракт токена USDC вблокчейне [Solana](https://solana.com/).
   4. [USDY](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09TQEHHDJ7) — смарт‑контракт токена USDY вблокчейне [Solana](https://solana.com/).
2. Контракты для реализации дополнительных возможностей в системе:
   1. [Trust](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09UTNG3ARE) контракт - контракт, позволяющий пользователю создать счет, которым можно поделиться с другим пользователем. На этот счет поэтапно будет переводиться заявленная владельцем сумма через заданные интервалы времени. В дальнейшем будет использоваться для доверительного управления активами (подробнее о работе траста [Описание продукта Trust (Product Description for Trust)](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09VA15AML0))

Для каждого из этих типов существуют свои особенности при пополнении.

# Газ при пополнении

Газ (комиссия) при пополнении складывается из двух основных частей:

1. Газ за отправку транзакции с пополнением - для проведения любой транзакции в блокчейне нужно платить комисиию сети.
2. Газ за обновление баланса контракта. Для распознавания поступивших на баланс контракта средств используется Controller ([Смарт-контракты и счета (Smart contracts and accounts)](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02)), который осуществляет постоянное сканирование всех транзакций в блокчейне. При обнаружении транзакции, отправленной на адрес счета Holders, Controller инициирует обновление баланса соответствующего контракта.

Сумма газа будет отличаться в зависимости от блокчейна и способа пополнения контракта.

# Способы пополнения контрактов

Существует два основных способа пополнить счёт:

1. Прямое пополнение
2. Пополнение с подключенного кошелька

## Прямое пополнение

Данный способ подразумевает прямой перевод средств на адрес контракта с любого друго адреса. Поддерживается только на новых версиях контрактов:

- TON (начиная с версии v3)
- USDT (TON) (начиная с версии v8)
- USDC (поддерживается на всех версиях)

При прямом пополнении средства поступают непосредственно на адрес контракта. Для распознавания поступивших средств используется Controller ([Смарт-контракты и счета (Smart contracts and accounts)](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02)), который осуществляет постоянное сканирование всех транзакций в блокчейне. При обнаружении транзакции, отправленной на адрес счета Holders, Controller инициирует обновление баланса соответствующего контракта. 

### Газ при прямом пополнении

Газ за отправку транзакции с пополнением - оплачивается пользователем и составляет стандартную для блокчейна сумму:\
Примечание: указаны максимальные значения комиссий. Фактическая комиссия может быть меньше - в этом случае неиспользованная часть возвращается на баланс кошелька пользователя.

1. Комиссия за проведение транзакции пополнения (оплачивается пользователем):
   1. TON - около 0.03 TON
   2. Solana - около 0.000005 SOL
2. Комиссия за обновление баланса контракта:
   1. TON - около 0.1 TON (оплачивается Holders)
   2. Solana - не взимается (благодаря использованию инструкции `deposit_card`)

### Пополнение через Changelly

Данный способ является одним из частных случаев прямого пополнения и позволяет пополнить контракт криптовалютами, которые не поддерживаются в сервисе, такими как:

- USDT (TRC-20)
- USDT (Polygon)
- USDT (SOL)
- USDT (ERC-20)
- USDC (Polygon)
- USDC (ERC-20)
- USDC (SOL) для контрактов в блокчейне TON

При таком способе пополнения Changelly принимает средства в указанных валютах на свои счета и осуществляет прямое пополнение счета пользователя в валюте контракта. Сервис Changelly позволяет клиентам пополнять счета различными криптовалютами, включая те, с которыми невозможно работать согласно регламенту MICA (например, USDT). Подробнее о таком пополнении читайте в [Changelly](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FG41J2EA).

## Пополнение с подключенного кошелька

Данный способ позволяет пополнить счет с кошелька, подключенного к Holders. Пользователь инициирует перевод необходимой суммы через интерфейс Holders, который затем через протокол подключения (TONConnect или специально разработанный протокол для Solana) запускает операцию пополнения в приложении кошелька. Пополнение доступно только для контрактов, где пользовательский кошелек имеет права Owner или Wallet Authority ([Смарт-контракты и счета (Smart contracts and accounts)](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02)). При таком способе пополнения не требуются дополнительные проверки от Controller, а все комиссии за транзакции оплачивает пользователь.\
Комиссия за такое пополнение зависит от нагрузки сети, но как правило не превышает следующих значений:

- 0.000005 SOL (для блокчейна Solana)
- 0.008 TON (для блокчейна TON)

### Газ при пополнении с подключенного кошелька

Примечание: указаны максимальные значения комиссий. Фактическая комиссия может быть меньше - в этом случае неиспользованная часть возвращается на баланс кошелька пользователя.

1. Газ за отправку транзакции с пополнением - оплачивается пользователем и составляет стандартную для блокчейна сумму:

- В TON ≈ 0.03 TON
- В Solana ≈ 0.000005 SOL

1. Газ за обновление баланса контракта - оплачивается также пользователем.

- В TON ≈ 0.1 TON
- В Solana не взимается.
