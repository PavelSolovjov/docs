# Что такое treasure-кошелек

Treasure-кошелек — это специализированный смарт-контракт, который выполняет роль treasury-аккаунта проекта для определенной криптовалюты и конкретного юридического лица. На этом счете аккумулируются средства для разных целей: комиссий, резервов и операционных бюджетов. Средства из treasure-кошелька используются для выплат партнерам, обеспечения ликвидности и финансирования бюджетов. Управление таким кошельком регулируется строгими правилами и процедурами.

# Виды treasure-кошельков в Holders

Сейчас в системе используется семь treasure-кошельков:

1. **Solana-treasure-usdc1** — активный treasure-кошелек компании Walleexer s.r.o. для операций с USDC в сети Solana.
2. **Solana-treasure-usdc2** — выведенный из эксплуатации treasure-кошелек компании Walleexer s.r.o. для операций с USDC в сети Solana.
3. **Ton-treasure1** — legacy treasure-кошелек компании Walleexer s.r.o. для операций с TON, который не поддерживает автоматические refund-операции. Используется для работы с первыми пользователями системы; все новые пользователи направляются в **Ton-treasure2**.
4. **Ton-treasure2** — активный treasure-кошелек компании Walleexer s.r.o. для операций с TON, поддерживающий refund-операции через QR-коды.
5. **Ton-treasure-usdt1** — legacy treasure-кошелек компании Walleexer s.r.o. для операций с USDT в сети TON, который не поддерживает автоматические refund-операции. Используется для работы с первыми пользователями системы; все новые пользователи направляются в **Ton-treasure-usdt2**. Технически это тот же кошелек, что и Ton-treasure1, а разделение сделано исключительно для целей учета.
6. **Ton-treasure-usdt2** — активный treasure-кошелек компании Walleexer s.r.o. для операций с USDT в сети TON, поддерживающий refund-операции через QR-коды.
7. **Holders Elysphere treasure USDT** — выведенный из эксплуатации treasure-кошелек компании Elysphere LTD для операций с USDT в сети TON.

# Вывод средств из treasure-кошелька

Вывод средств из treasure-кошелька выполняется исключительно уполномоченным оператором, у которого есть доступ к `treasure authority`, то есть к специализированному блокчейн-кошельку с правом подписи транзакций на списание средств. Формирование транзакции выполняется оператором через интерфейс Backoffice. Операции вывода могут быть выполнены только на адреса, включенные в whitelist смарт-контракта treasure-кошелька. Такой режим работы гарантирует безопасность размещенных на нем средств.\
Направления вывода средств:

- транзитные кошельки VASP,
- биржи VASP,
- холодные кошельки VASP, включенные в whitelist,
- клиентские криптовалютные аккаунты для refund-операций.
