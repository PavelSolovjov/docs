---
title: "Ключевые файлы"
---

| Файл | Назначение |
| :-- | :-- |
| `api/fees.ts` | Чистые функции расчета комиссий и проверка лимитов |
| `api/routes/instance-admin.ts` | Все billing- и settlement-действия API |
| `api/routes/check-balance.ts` | `collectCreationFee()`, on-chain сбор комиссий |
| `api/routes/cheques.ts` | `INSERT` в `fee_ledger` при создании чека |
| `api/routes/relayer.ts` | `INSERT` и `UPDATE` для claim fee |
| `api/routes/breakage.ts` | `INSERT` breakage fee при истечении срока |
| `src/pages/InstanceDashboard.tsx` | `RevenueTab`, все billing-подразделы интерфейса |
| `src/components/admin/AdminRevenueTab.tsx` | Глобальный обзор revenue для platform admin |
| `src/components/admin/AdminFeeTiersTab.tsx` | CRUD для fee tiers, используется platform admin |
| `db/init.sql` | `fee_ledger`, около строки 341, и `fee_tiers`, около строки 285 |
| `db/migrations/035–037` | Уже существующие billing-миграции |
| `db/migrations/038–044` | Запланированные migration-и для distribution и платежей |
