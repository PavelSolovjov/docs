# Для чего используется стейкинг через транзакцию

Стейкинг через транзакцию используется как альтернативный способ отправки монет в стейкинг в тех случаях, когда некостодиальный кошелек пользователя не поддерживает подключение через TON Connect или не имеет встроенного интерфейса для стейкинга.\
При использовании транзакций нельзя вывести часть стейка, как в других методах: можно вывести только всю сумму целиком.

<Info>
  **Важно:** отправка монет в стейкинг выполняется исключительно из некостодиальных кошельков. При отправке средств с кастодиального кошелька или биржевого аккаунта они будут безвозвратно утеряны.
</Info>

# Адрес пула

Чтобы отправлять и получать средства через транзакцию, необходимо узнать адрес пула, в который вы планируете отправить средства. Адрес любого пула можно найти [на странице пулов](https://tonwhales.com/staking) сайта [tonwhales.com](http://tonwhales.com).

1. Перейдите на https://tonwhales.com/staking
2. Выберите пул, в который хотите отправить средства, и нажмите на его изображение.
3. Выберите очередь, в которую хотите отправить средства, и нажмите Stake.
4. Введите любую сумму больше 50 для пулов Ton Whales и больше 10 для P2P или Ledger.
5. Нажмите Stake via any wallet.
6. Скопируйте адрес пула. Он понадобится и для пополнения, и для вывода.

# Пополнение через транзакцию

1. В вашем кошельке нажмите кнопку отправки средств.
2. Введите сумму, которую хотите отправить в стейкинг.
3. В поле "Comment", то есть memo, введите `Deposit`.
4. Подтвердите транзакцию. Обратите внимание, что за отправку монет в стейкинг нужно заплатить газ, то есть комиссию, в размере 0.2 TON. Неиспользованная часть комиссии будет возвращена после отправки. Рекомендуется держать на балансе 0.4 TON для оплаты газа при выводе средств.
5. В ответном сообщении вы получите обратно оставшуюся часть комиссии с комментарием `"Stake accepted"`.
6. Ваши средства успешно отправлены в пул и начнут участвовать в стейкинге после завершения текущего цикла. Прибыль будет зачисляться на стейкинговый баланс после каждого полного цикла. Таким образом, первая прибыль появится после времени, оставшегося до конца текущего цикла, плюс одного полного цикла, то есть через 36 часов.

<Info>
  Если сумма стейкинга была возвращена после попытки отправки транзакции, проверьте правильность адреса и комментария. Комментарий должен быть написан с заглавной буквы и без лишних пробелов в начале и в конце.
</Info>

# Вывод средств через транзакцию

1. В кошельке нажмите кнопку отправки средств.
2. В поле суммы укажите 0.2 TON. Эта сумма является комиссией за транзакцию, а сам стейк будет выведен полностью.
3. В поле "Comment", то есть memo, введите `Withdraw`.
4. В поле адреса укажите адрес пула, в который ранее были отправлены средства.
5. Подтвердите транзакцию.
6. Запрос на вывод отправлен. Повторите эту же процедуру после завершения ближайшего стейкингового цикла. Средства поступят на ваш баланс в течение нескольких минут.
