# Что такое Whales Connect

**Whales Connect** — это backend-сервис для экосистемы Whales. Он обеспечивает управление сессиями подключения кошельков, доставку команд, то есть транзакций и подписей, push-уведомления, интеграции TonConnect и общую инфраструктуру данных для продуктов, включая курсы, балансы и другие данные.\
По сути, это единый backend для кошельков и приложений Whales: сервис "соединения" между кошельком и приложением, а также платформа общих API для блокчейна, курсов, метаданных, отправки транзакций и других задач.\
Репозиторий: https://github.com/tonwhales/whales-connect\
Язык: Typescript

# Для чего он используется

- **Подключение кошелька к приложению (Connect)** — обеспечивает безопасное установление соединения между кошельком пользователя и внешними приложениями. Приложение инициирует запрос на подключение, пользователь подтверждает его в интерфейсе кошелька, после чего приложение получает авторизованный доступ к адресу кошелька и возможность отправлять запросы на выполнение операций.
- **Доставка команд в кошелек (command)** — позволяет приложениям отправлять задания в кошелек пользователя. Приложение создает задачу, например транзакцию или подпись данных, система проверяет активность сессии, сохраняет задачу и доставляет ее в кошелек через push-уведомления или протокол TonConnect. Пользователь может подтвердить или отклонить операцию в приложении кошелька.
- **Общее хранилище сессий (connect read/write)** — дает приложениям возможность сохранять и читать данные, связанные с адресом кошелька, в формате key-value. Все операции выполняются с согласия пользователя и проверкой подписи сессии. Эта функция предназначена для хранения кэша, пользовательских настроек и состояния приложения без необходимости разворачивать собственный backend.
- **Инфраструктура экосистемы** — централизованная платформа, предоставляющая единый API для получения курсов валют, балансов кошельков, истории транзакций, функций стейкинга, проверки смарт-контрактов, отправки транзакций и интеграции TonConnect. Это позволяет разработчикам кошельков и приложений не дублировать логику и не взаимодействовать с блокчейном напрямую.
- **Push-уведомления** — система регистрации устройств по адресам кошельков и доставки уведомлений пользователям. Включает уведомления о новых Connect-командах, запросах TonConnect и других событиях. Реализована через интеграцию с Expo Push и собственные обработчики уведомлений.

# Какие продукты его используют

- [**Tonhub**](/ru/business-overview-1) — использует Whales Connect как основной backend для создания кошельков, получения актуальных валютных курсов, интеграции с внешними сервисами, выполнения транзакций и отправки push-уведомлений пользователям.
- [**Staking**](/ru/business-overview) — использует сервис для расчета доходности стейкинга и получения текущих курсов криптовалют.
- **Внутренние сервисы экосистемы** — включают staking indexer, compiler и TonhubAPI для mainnet, testnet и sandbox-окружений. Whales Connect выступает центральным backend для всех кошельков и приложений в экосистеме.
