# Создание профиля: шаги пользователя

Переход пользователя по шагам показан на примере интеграции в мобильный кошелек Tonhub.

1. Пользователь нажимает на баннер на главном экране кошелька. Кошелек перенаправляет его в Holders WebApp.

3. Экран выбора резидентства, то есть pre-onboarding. На этом этапе система применяет ограничения в соответствии со списком стран, загруженным из Holders backend. Если страна резидентства пользователя подпадает под текущие ограничения, пользователь перенаправляется на форму заявки. На текущий момент, январь 2026 года, ограничения распространяются только на резидентов стран, входящих в санкционные списки [OFAC](https://ofac.treasury.gov/sanctions-programs-and-country-information).

4. Ввод и подтверждение номера телефона, OTP. Пользователь вводит свой номер телефона и подтверждает его с помощью кода, полученного в SMS. По умолчанию система предлагает код страны, выбранный пользователем на этапе pre-onboarding, однако его можно изменить, нажав на соответствующий флаг страны. Доставка кода подтверждения реализована в партнерстве с сервисом [Twilio](https://www.twilio.com/en-us). После подтверждения номера телефона в базе данных Holders создается профиль пользователя, а также принимаются политики Holders, Privacy Notes. Версия принятых политик тоже сохраняется в базе сервиса.

   На странице есть две дополнительные опции:
   - **Resend code** — функция повторной отправки кода авторизации с интервалом 40 секунд. Количество запросов ограничено пятью в день, однако это ограничение может снять администратор Backoffice на странице управления пользователем.
   - **Didn't receive the code?** — функция открытия модального окна с информационным сообщением: "**Not received the code?** Check your number, it may have been entered with an error. It is also possible that airplane mode is turned on or there is no access to the operator's network. Or write to support, we will try to help you" и возможностью связаться с поддержкой через встроенный сервис Intercom.

5. Подтверждение email-адреса. Пользователь вводит адрес и нажимает `Continue`. Система проверяет адрес на мошеннические признаки с помощью внешнего сервиса [_Postmark_](https://postmarkapp.com/). После успешной проверки пользователь получает письмо с шестизначным цифровым кодом подтверждения, который нужно ввести в соответствующее поле. Также пользователь может подтвердить email, нажав специальную кнопку в полученном письме. Если письмо не пришло, у пользователя есть возможность вернуться к экрану ввода адреса и повторить процесс. Важно: действует ограничение — не более 3 писем с кодом подтверждения в течение 24 часов.
6. Начало верификации. Пользователь попадает на экран с предложением пройти verification и нажимает `Continue`.

   По итогам модерации партнер отправляет webhook в Holders с одним из следующих решений:
   1. Модерация успешно пройдена — пользователь получает push-уведомление и может начать пользоваться сервисом.
   2. Модерация не пройдена — пользователь получает push-уведомление о невозможности использования сервиса с указанием причины. В случае неокончательного решения, например при загрузке изображения документа низкого качества, пользователю предоставляется возможность пройти verification повторно.

   - Account
   - Private Trust

# Вход в профиль

Пользователь входит в уже существующий аккаунт внутри расширения Holders в партнерском кошельке.

- Login by phone number
- Login by seed phrase

## Вход по номеру телефона

Используется, когда пользователь уже пользовался сервисом или хочет привязать к своему профилю дополнительный адрес кошелька, число кошельков, связанных с одним профилем, не ограничено.

1. Пользователь переходит в приложение Holders из интерфейса кошелька. Конкретный сценарий перехода зависит от партнера: например, в Tonhub пользователь нажимает на баннер на главном экране кошелька.
2. Пользователь выбирает страну резидентства, пролистывая список флагов или вводя название страны в поле поиска. Система поддерживает ввод как полных названий стран, так и сокращений, например UAE или USA, на любом языке. При входе в существующий аккаунт страна пользователя нам уже известна, однако до ввода номера телефона нельзя понять, пытается ли пользователь войти в существующий профиль или создать новый.
3. Пользователь вводит номер телефона, который уже использовал в сервисе. После нажатия кнопки `Continue` он переходит на страницу подтверждения номера. На этом этапе также автоматически принимается текущая _Privacy Policy_.
4. При правильном вводе кода подтверждения пользователь попадает на страницу последнего созданного счета.

## Вход по seed-фразе

Используется, когда пользователь знает seed phrase от TON-кошелька, привязанного к профилю в Holders. После ввода seed phrase профиль открывается вместе с кошельком. Чтобы войти в профиль, нужно перейти в раздел `Cards` в верхней части кошелька и затем нажать кнопку `Continue` — пользователь будет перенаправлен на страницу последнего созданного счета.
