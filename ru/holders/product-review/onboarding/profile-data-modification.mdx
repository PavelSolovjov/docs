# Изменение номера телефона

Пользователи могут самостоятельно менять свой номер телефона в любое время прямо в Holders. Для этого нужно:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current phone number
4. Go to the number replacement page
5. Enter the new phone number
6. Confirm the new number with a code (similar to the procedure when creating a profile)

**Важно:** число изменений номера телефона в день не ограничено, но количество подтверждений нового номера ограничено 5 попытками.

# Изменение email-адреса

Изменить email-адрес может только сам пользователь. Процедура изменения включает:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current address
4. Enter the new email address
5. Confirm the new address through a verification code

Система проверяет email-адрес через внешний сервис Postmark на предмет мошенничества. После успешной проверки пользователь получает письмо с шестизначным кодом подтверждения либо может подтвердить адрес, нажав специальную кнопку в полученном письме.

# Изменение адреса проживания

Чтобы изменить адрес проживания, нужно:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current address
4. Correct the changed fields
5. Confirm saving

# Удаление данных профиля

Пользователи имеют право удалить свои персональные данные в соответствии с требованиями GDPR. Чтобы запросить удаление данных, нужно:

1. Contact service support by clicking on the corresponding icon on the Cards screen or by going to settings
2. Specify full name, email address and phone number
3. Confirm the data deletion request
4. Данные будут удалены в соответствии с требованиями GDPR, и пользователь получит уведомление об этом
