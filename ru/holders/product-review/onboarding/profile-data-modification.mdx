# Phone Number Change

Users can independently change their phone number at any time directly in Holders. To do this, you need to:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current phone number
4. Go to the number replacement page
5. Enter the new phone number
6. Confirm the new number with a code (similar to the procedure when creating a profile)

**Important:** The number of phone number changes per day is not limited, but the number of confirmations for a new number is limited to 5 attempts.

# Email Address Change

The email address can only be changed by the user themselves. The change procedure includes:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current address
4. Enter the new email address
5. Confirm the new address through a verification code

The system checks the email address using the external Postmark service for fraud. After successful verification, the user receives an email with a six-digit numeric confirmation code or can confirm the address by clicking a special button in the received email.

# Residential Address Change

To change the residential address, you need to:

1. Go to the "Cards" section on the main wallet page
2. Click the "Settings" button in the right part of the bottom panel
3. In the contact information section, click on the current address
4. Correct the changed fields
5. Confirm saving

# Profile Data Deletion

Users have the right to delete their personal data in accordance with GDPR requirements. To request data deletion, you need to:

1. Contact service support by clicking on the corresponding icon on the Cards screen or by going to settings
2. Specify full name, email address and phone number
3. Confirm the data deletion request
4. Data will be deleted according to GDPR requirements and the user will be notified about this
