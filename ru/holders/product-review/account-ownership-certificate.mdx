# Что такое сертификат владения счетом

Сертификат подтверждает право собственности конкретного физического лица на децентрализованные счета в системе Holders. Этот документ служит официальным аналогом банковской справки о владении счетом и может использоваться как подтверждающая документация там, где это требуется, включая бухгалтерии организаций при получении зарплатных выплат в криптовалюте.

# Travel Rule

[Travel Rule](https://www.fatf-gafi.org/en/publications/Fatf-recommendations/Fatf-recommendations.html) is an anti-money laundering (AML) requirement under which transfers between financial institutions (banks, cryptocurrency exchanges, and others) must include basic information about the sender and recipient (including name, account number/address, in some cases residential address and other data) along with the payment. This requirement enables tracking the origin and movement of funds, as well as preventing money laundering and terrorism financing. A bank account ownership certificate confirms that a specific individual or legal entity is the lawful owner of the specified account.\
Цель этого документа:

- When conducting verification of funds origin and ensuring compliance with Travel Rule requirements, a financial service must verify the following:
  - The bank account from which funds originate or to which funds are directed belongs specifically to this client;
  - The owner's personal data specified in the certificate corresponds to the information that is transmitted and stored as part of Travel Rule compliance.

Таким образом, сертификат служит документальным подтверждением для идентификации клиента и процедур противодействия отмыванию средств (KYC/AML), а также одним из оснований для подтверждения корректности данных, передаваемых в соответствии с требованиями Travel Rule.

# Данные сертификата

### Данные компании, выпускающей сертификат

- Logo
- Address
- Identification number
- Business activity
- Contacts

### Данные пользователя

- First name, last name
- Country of residence
- Verification status
- Partner who conducted verification
- Date of last verification in the system

### Подтверждение владения

- Account owner's wallet address - the wallet address that creates proof of ownership
- Account ownership confirmation - cryptographic element confirming the fact of ownership and control over the account, includes data that can be verified by third parties (random data from the server used for confirmation).
- Signature - signature with the wallet's private key.
- Public key - public key of the verified wallet. Generated from the blockchain or from proof of ownership

### Информация о счете

- Account creation date
- Account (contract) address
- Account currency
- Account blockchain

### Дополнительно

- VASP seal
- VASP director's signature

# Proof of ownership в сертификате

Для подтверждения владения кошельком со стороны пользователя применяется механизм proof of ownership, реализованный на основе стандарта TON Connect ([документация TON Connect](https://github.com/ton-connect/sdk)).\
При подключении криптовалютного кошелька к веб-приложению система, согласно стандарту TON Connect, запрашивает подтверждение владения. Это подтверждение создается путем подписи приватным ключом следующих данных:

- Cryptocurrency wallet address
- Domain name of the connecting application
- Timestamp of confirmation creation
- Random data (payload) generated by the server

После формирования proof of ownership кошелек отправляет указанный набор данных на сервер вместе с криптографической подписью, созданной приватным ключом, для последующей проверки.
