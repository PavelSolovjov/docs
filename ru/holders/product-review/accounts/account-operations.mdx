# Операции по счету

1. **Открытие нового счета** — создание нового счета с собственным балансом и возможностью выпуска карт.
2. **Закрытие счета** — процедура окончательного прекращения обслуживания счета, после которой операции по нему становятся невозможны, а оставшиеся средства переводятся по установленным правилам.
3. **Пополнение счета** — зачисление средств на счет через доступные методы депозита.
4. **Вывод со счета** — перевод средств со счета с использованием доступных способов вывода.
5. **Платежи** — операции по отправке средств со счета через доступные методы перевода.
6. **Установка лимитов счета** — процедура определения и настройки ограничений на траты, например лимита на одну операцию, дневного, месячного и других временных ограничений.

# Открытие нового счета

Открытие нового счета доступно всем пользователям Holders, имеющим резидентство стран, не входящих в санкционные списки. Количество счетов, которые может открыть один пользователь, не ограничено.

## Условия открытия нового счета

- Профиль пользователя должен пройти процедуру KYC-верификации

## Доступные валюты счета

- **USDC (SOL)** — публично доступная валюта для всех типов счетов
- **TON** — публично доступная валюта для обычных счетов, не vesting
- **USDY (SOL)** — сейчас находится в режиме тестирования, будет доступна и для обычных, и для vesting-счетов
- **USDT (TON)** — поддержка прекращена

# Закрытие счета

Закрытие счета — это операция вывода счета из эксплуатации, после которой становятся невозможны пополнение, вывод и переводы. Счет исчезает из пользовательского интерфейса и переводится в финальный статус `CLOSED`. Перед выполнением процедуры система проверяет, что к счету не привязаны активные карты. Оставшиеся средства, если они есть, переводятся на кошелек владельца счета в соответствии с установленными правилами.

<Info>
  **Важно:** если возврат поступает на уже закрытый счет, автоматический перевод на активный счет не выполняется. Такой возврат переводится в статус ожидающего платежа и распределяется только после обращения владельца закрытого счета в техническую поддержку.
</Info>

# Пополнение счета

Чтобы пользоваться основными функциями сервиса, пользователю нужно пополнить свой [smart contract](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02), который выступает в роли банковского счета. Пользовательские [bank cards](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FE5D3DLM) привязаны к этому смарт-контракту для проведения платежей. При оплате [банковской картой](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FE5D3DLM) средства списываются со счета пользователя, к которому привязана карта.

# Способы пополнения счета

1. **Со savings account, то есть с баланса подключенного кошелька** — позволяет перевести средства из подключенного кошелька на счет.
2. **С другого кошелька** — позволяет пополнить счет в валюте, отличной от валюты счета, с автоматической конвертацией.
3. **Пополнение по реквизитам, direct funding** — дает возможность перевести средства на счет из любого источника по реквизитам счета.
4. **С биржи** — позволяет зачислить средства на баланс счета с биржевого баланса.

<Info>
  В системе Holders + Tonhub для счетов используется следующая терминология:

  - **Spending accounts** — счета в Holders, предназначенные для привязки карт и совершения покупок
  - **Savings accounts** — балансы подключенного кошелька в разных валютах, используемые для хранения средств
</Info>

# Комиссии gas при пополнении счета

Комиссии gas, то есть комиссия за пополнение счета, состоят из двух основных частей:

1. Gas за отправку транзакции пополнения — любая транзакция в блокчейне требует оплаты сетевой комиссии. Эту часть оплачивает пользователь.
2. Gas за обновление баланса контракта. Чтобы распознать поступившие на баланс контракта средства, используется Controller, который непрерывно сканирует транзакции в блокчейне. Когда система обнаруживает транзакцию, отправленную на адрес счета Holders, Controller инициирует обновление соответствующего баланса контракта. Эту часть оплачивает Holders.

Размер gas зависит от блокчейна и способа пополнения контракта.

## Размер комиссий

1. Комиссия за проведение транзакции пополнения:
   1. **TON** — примерно **0.03 TON**
   2. **Solana** — **0.000005 SOL**
1. Комиссия за обновление баланса контракта:
   1. **TON** — примерно **0.1 TON**, оплачивает Holders
   2. **Solana** — **не взимается**

Примечание: указаны максимальные значения комиссий. Фактическая комиссия может быть ниже; в этом случае неиспользованный остаток возвращается на баланс кошелька пользователя.

## Пополнение со savings account

Это самый простой способ пополнить счет. Функция доступна, если на savings account есть положительный баланс в соответствующей валюте. Пользователь указывает нужную сумму и подтверждает операцию пополнения. Средства зачисляются на счет в течение нескольких минут.

## Пополнение с другого кошелька

Этот способ пополнения работает через партнерский сервис [Changelly](https://changelly.com/). Он позволяет пополнять счет криптовалютами, которые платформа не поддерживает напрямую:

- **USDT (TRC-20)**
- **USDT (Polygon)**
- **USDT (SOL)**
- **USDT (ERC-20)**
- **USDC (Polygon)**
- **USDC (ERC-20)**
- **USDC (SOL) для контрактов в сети TON**

**Как это работает:** пользователь отправляет средства в одной из перечисленных валют на адрес [Changelly](https://changelly.com/), после чего сервис автоматически конвертирует их и зачисляет деньги на счет в нужной валюте. Это особенно удобно для использования криптовалют, ограниченных [регулированием MICA](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32023R1114), например [USDT](https://tether.to/). Комиссию за обмен покрывает Holders. Обычно такое пополнение занимает до 60 минут.\
В рамках интеграции с Holders сервис [Changelly](https://changelly.com/) поддерживает обмены только по фиксированному курсу, то есть `Fix rate`. При таком способе курс фиксируется на определенное время, поэтому клиент заранее знает точную итоговую сумму. На завершение операции дается 3 часа. Такой подход возможен потому, что обмен выполняется только между стабильными валютами.

## Пополнение по реквизитам (direct funding)

Этот способ предполагает прямой перевод средств на адрес контракта с другого адреса в той же сети. Он поддерживается только в более новых версиях контрактов:

- **USDC, поддерживается на всех версиях**
- **TON, начиная с версии v3**
- **USDT (TON), начиная с версии v8**

При direct funding средства поступают напрямую на адрес контракта. Чтобы распознать поступление, используется Controller, который непрерывно сканирует транзакции в блокчейне. Когда он обнаруживает перевод на адрес счета Holders, он инициирует обновление баланса соответствующего контракта.\
Пополнение по реквизитам — это классическое прямое пополнение счета транзакцией на его адрес. Оно позволяет пополнить счет, поделиться реквизитами счета или создать платежную ссылку на пополнение и отправить ее другу, который сможет внести средства через интерфейс [Changelly](https://changelly.com/), даже если у него нет аккаунта в Holders.

- Пополнить счет напрямую по реквизитам
- Поделиться реквизитами счета с другими пользователями
- Создать платежную ссылку вида `https://hldrs.me/th/pay/cmgzamplv39rk3s3gkj2mia1x` для пополнения и отправить ее другому пользователю

При использовании платежной ссылки получатель может пополнить счет через интерфейс [Changelly](https://changelly.com/) без необходимости создавать аккаунт в сервисе Holders.

Пользовательский интерфейс дает пошаговые инструкции по переводу средств с наиболее популярных криптовалютных торговых платформ. Пользователь выбирает нужную биржу и, следуя предложенным инструкциям, завершает процедуру пополнения счета.

Биржи, для которых доступны отдельные инструкции:

# Вывод со счета

Вывод средств выполняется тремя возможными способами:

- На savings account — на баланс кошелька, привязанного к Holders.
- На другой кошелек — на произвольный адрес.
- На Holders account — на другой счет внутри системы Holders.

## На savings account

Этот механизм вывода обеспечивает высокий уровень безопасности и сохраняет некастодиальную природу сервиса, поскольку перевод средств выполняется только на заранее авторизованный клиентский адрес, и при этом является gas-free для пользователя: транзакция подписывается и оплачивается сервисным [controller](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02) Holders. Таким образом, [Holders smart contract](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02) выполняет вывод средств на кошелек клиента без необходимости дополнительного разрешения или подписи со стороны владельца счета.

## На другой кошелек

Если controller мог бы выводить деньги со счета на любой адрес, это нарушало бы соглашение между Holders и клиентом. В таком случае controller мог бы забирать деньги с любого счета без разрешения владельца. Это делало бы [Holders smart contract](https://whales.enterprise.slack.com/docs/T045HLK3YLE/F09FGC4GU02) централизованным и небезопасным. Аудиторы и пользователи справедливо могли бы сказать, что controller, которым управляет Holders, способен украсть все средства со всех счетов. Чтобы избежать этого, используется multi-signature.\
Multi-signature — это механизм, при котором операция требует подписей и со стороны клиента, и со стороны Holders. Это дает следующее:

- клиент лично авторизует все выводы со своего счета на внешние адреса
- Holders проверяет все выводы на соответствие требованиям AML/KYT и другим правилам
- Holders оплачивает комиссии за транзакции вместо клиента

Такой подход сохраняет безопасность и позволяет безопасно выводить средства на внешние адреса.

### Вывод в другие блокчейны

Чтобы обеспечить вывод средств в другие сети, в систему интегрирован [Changelly](https://changelly.com/) по тому же принципу, что и для пополнений. [Changelly](https://changelly.com/) позволяет пользователю выбрать сеть, в которой он хочет получить средства. Пользователь выбирает сеть, указывает адрес получателя и подтверждает перевод. Gas за операцию оплачивает Holders.

## На другой счет Holders

Этот способ позволяет выводить или переводить средства на другие счета Holders по номеру телефона или email. Важное условие: счет получателя должен заранее разрешить входящие переводы, нажав соответствующую кнопку на главной странице.

# Платежи

Доступны следующие типы платежей:

- **Holders Account** — на другой счет в системе Holders. Этот перевод уже описан выше в разделе вывода со счета.
- **External Wallet** — на произвольный адрес. Этот перевод уже описан выше в разделе вывода со счета.
- **SEPA** — банковские переводы в EUR внутри Европы.
- **SWIFT** — международные банковские переводы в любой валюте.

## SEPA

SEPA-перевод — это безналичный банковский перевод в евро между странами SEPA-зоны, включая ЕС, ЕЭЗ и другие страны, который выполняется по единым стандартам: быстро, с фиксированной комиссией и без конвертации валюты.\
SEPA-переводы в системе Holders обрабатываются вручную сотрудниками [службы поддержки](https://help.holders.io/en/) через платежного партнера [Triple-A](https://www.triple-a.io/). Для отправки перевода на счете клиента должны быть доступны сумма перевода и комиссия за его обработку. Сейчас в Holders не реализована прямая отправка SEPA-переводов, поэтому все операции выполняются через партнера [Triple-A](https://www.triple-a.io/). Перевод занимает от 1 рабочего дня.

### Данные получателя

- Полное имя получателя в соответствии с банковскими документами
- IBAN получателя
- BIC/SWIFT-код банка получателя, если требуется
- Назначение платежа
- Сумма в EUR

### Tariff

За обработку SEPA-платежа взимается стандартная комиссия, состоящая из фиксированной части и процента от общей суммы перевода. Комиссия за отправку SEPA-платежей составляет 3.5 USD плюс 1.5% от общей суммы платежа с учетом фиксированной части. Это означает, что при отправке более крупной суммы процентная часть комиссии растет пропорционально.

## SWIFT

SWIFT-перевод — это международный банковский перевод через сеть SWIFT, который позволяет отправлять деньги в любую страну и в любой валюте, но обычно сопровождается более высокой комиссией, возможной конвертацией и более долгими сроками по сравнению с SEPA. Сроки обычно составляют от 1 до 5 рабочих дней.\
SWIFT-переводы в системе Holders обрабатываются вручную сотрудниками [службы поддержки](https://help.holders.io/en/) через платежного партнера [Triple-A](https://www.triple-a.io/). Для отправки перевода на счете клиента должны быть доступны сумма перевода и комиссия за его обработку. Сейчас в Holders не реализована прямая отправка SWIFT-переводов, поэтому все операции выполняются через платежного партнера [Triple-A](https://www.triple-a.io/).

### Данные для отправки

Личные данные:

- **First Name**
- **Last Name**
- **Gender**
- **Date of Birth**
- **Email address**
- **Contact number (Mobile)**
- **Occupation**
- **Country of residence**
- **Address**
- **Zip code**
- **City**
- **Province / state**

Идентификация:

- **ID type**
- **ID number**
- **Nationality**
- **Issuing country**
- **Issue Date**
- **Expiry Date**

### Тариф

Комиссия за SWIFT-платеж состоит из:

- фиксированной части: 50 USD
- процентной части: 2.3% от суммы перевода, то есть 0.8% + 1.5%

Итоговая комиссия рассчитывается так: 50 USD + 2.3% от суммы перевода.\
При отправке SWIFT-платежа можно выбрать один из двух способов оплаты комиссий:\
**SHA (Shared), совместная оплата:**

- комиссии делятся между отправителем и получателем
- получатель может получить меньшую сумму из-за удержаний банками-корреспондентами
- подходит в случаях, когда отправителю важно снизить собственные расходы

**OUR, полная оплата отправителем:**

- отправитель оплачивает все комиссии банков-посредников
- получатель получает ровно указанную сумму без удержаний
- дополнительная фиксированная комиссия: 25 USD
- подходит, когда важно, чтобы получатель получил полную сумму

# Настройка блокчейн-лимитов

Пользователь может задавать ограничения на расходование средств по счету, которые фиксируются на уровне блокчейна. Система поддерживает три основных типа лимитов:

- **Лимит на одну отдельную транзакцию**
- **Дневной лимит расходов**
- **Месячный лимит расходов**

Лимиты задаются индивидуально для каждого счета. Подробная информация о том, как они работают, приведена [в соответствующем документе](/ru/Issuerblockchainlimits).

# Изменение названия счета

Пользователь может в любой момент изменить название счета, отображаемое в интерфейсе. Для этого нужно:

1. выбрать счет, название которого нужно изменить
2. нажать на его заголовок в верхней части интерфейса
3. ввести желаемое имя, длина названия ограничена 50 символами
4. сохранить новое название
