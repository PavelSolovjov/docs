# Что такое бренд счета

Бренд счета — это идентификатор, который показывает источник создания счета в системе. Например, если счет был создан через мобильное приложение [Tonhub](https://gettonhub.com/), его брендом будет `Tonhub`. При создании счета бренд записывается в специальное поле базы данных. Для всех счетов, созданных до внедрения системы брендов, то есть до 19 декабря 2024 года, по умолчанию установлен бренд `Holders`.\
Система брендов позволяет вести статистику и расчеты с партнерами, через чьи клиентские приложения создавались счета. Кроме того, бренд определяет ограничения на отображение счетов в разных клиентских приложениях.\
У одного пользователя могут быть счета с разными брендами, если он использовал разные клиенты для их создания.

# Что такое бренд пользователя

Бренд пользователя — это идентификатор, который показывает источник появления пользователя в системе. Этот идентификатор определяется во время первой пользовательской сессии и сохраняется в профиле. Бренд профиля влияет на список push-уведомлений, которые будут отправляться пользователю. Например, текст уведомлений для бренда [Tonhub](https://gettonhub.com/) и для бота [@card](https://t.me/card) будет различаться.

# Какие бренды существуют

Сейчас существуют следующие бренды:

- **Holders** — счета, созданные в веб-версии приложения или до внедрения системы брендов.
- **Tonhub** — счета, созданные в мобильном кошельке [Tonhub](https://gettonhub.com/). Доступны для просмотра только в кошельке Tonhub, веб-версии и боте [@card](https://t.me/card).
- **Tonkeeper** — счета, созданные в партнерском кошельке [Tonkeeper](https://tonkeeper.com/).
- **@card Bot** — счета, созданные в [боте](https://t.me/card). Отображаются в боте или в веб-версии.

# Отображение счетов с разными брендами в разных клиентах

# Схема верификации бренда

![Screenshot2025 10 13at13 22 56](/images/Screenshot2025-10-13at13.22.56.png)

1. Клиент, в данном случае Wallet app, передает данные бренда в Issuer, то есть в базу данных.
2. Issuer, то есть база данных, создает сессию и предоставляет список пользовательских счетов, соответствующих этому бренду.
3. Токен сессии сохраняется в клиентском storage и передается в веб-версию Holders.
4. Веб-версия Holders отображает список счетов, которые разрешены к показу со стороны Issuer.
