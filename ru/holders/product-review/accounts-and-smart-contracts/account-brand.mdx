# Что такое бренд счета

An account brand is an identifier that indicates the source of account creation in the system. For example, if an account was created through the [Tonhub](https://gettonhub.com/) mobile application, its brand will be "Tonhub". When creating an account, the brand is recorded in a special database field. For all accounts created before the brand system implementation (before December 19, 2024), the "Holders" brand is set by default.\
The brand system enables statistics tracking and settlements with partners whose client applications were used to create accounts. Additionally, the brand determines restrictions on account display in various client applications.\
A user can have accounts with different brands if they used different clients to create them.

# Что такое бренд пользователя

A user brand is an identifier that indicates the source of a user's appearance in the system. This identifier is determined during the user's first session and is saved in the user profile. The profile brand affects the list of push notifications that will be sent to the user (for example, notification text for the [Tonhub](https://gettonhub.com/) brand and the [@card](https://t.me/card) bot will differ).

# Какие бренды существуют

Currently, the following brands exist:

- **Holders** — accounts created in the web version of the application or before the brand system implementation.
- **Tonhub** — accounts created in the [Tonhub](https://gettonhub.com/) mobile wallet. Available for viewing only in the Tonhub wallet, web version, and [@card](https://t.me/card) bot.
- **Tonkeeper** — accounts created in the [Tonkeeper](https://tonkeeper.com/) partner wallet.
- **@card Bot** — accounts created in the [bot](https://t.me/card). Displayed in the bot or web version.

# Схема верификации бренда

![Screenshot2025 10 13at13 22 56](/images/Screenshot2025-10-13at13.22.56.png)

1. The client (in this case Wallet app) passes brand data to the Issuer (DB).
2. Issuer (DB) creates a session and provides a list of user accounts corresponding to the brand.
3. The session token is stored in the client storage and passed to the web version of Holders.
4. The web version of Holders displays the list of accounts allowed for display by the Issuer.
