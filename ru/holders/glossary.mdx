# Общие термины

| Term | Definition |
| :--- | :--- |
| API | Application Programming Interface — набор правил и протоколов для взаимодействия между программными компонентами |
| Blockchain | Распределенная база данных, состоящая из цепочки блоков, каждый из которых содержит криптографическую ссылку на предыдущий |
| Smart contract | Программа, которая автоматически исполняет и обеспечивает выполнение условий соглашения в блокчейне. Ее код хранится и исполняется в сети без посредников, по заранее заданным правилам. |
| SDK | Software Development Kit — набор инструментов разработки, который позволяет создавать приложения для определенной платформы или интегрироваться с сервисом |
| Non-custodial | Модель, при которой сервис не хранит приватные ключи и не контролирует средства пользователя; пользователь управляет ими самостоятельно и может в любой момент вывести средства из своего смарт-контракта |
| Stablecoin | Вид криптовалюты, предназначенный для поддержания стабильной стоимости за счет привязки к резервному активу, обычно к доллару США в соотношении 1:1 |
| Visa | Международная платежная система, которая обрабатывает электронные платежи по всему миру через сеть банков-эмитентов и эквайеров, поддерживая дебетовые и кредитные карты |
| Bank issuer | Финансовое учреждение, которое выпускает платежные карты и отвечает за карточные транзакции, выступая эмитентом в платежной экосистеме |
| Счет | Программная оболочка над смарт-контрактом, которая превращает сам контракт в удобный для пользователя "банковский" счет |
| SEPA | Single Euro Payments Area — единая еврозона платежей, которая обеспечивает упрощенные безналичные переводы между банками стран-участников, например ЕС, ЕЭЗ, Швейцарии, Великобритании и других, почти так же просто, как внутри одной страны |
| SWIFT | Society for Worldwide Interbank Financial Telecommunications — международная система банковских переводов через сеть SWIFT, позволяющая отправлять деньги в любую страну и в любой валюте, но обычно с более высокой комиссией и более долгими сроками, чем SEPA |
| MiCA | Markets in Crypto-Assets Regulation (EU) 2023/1114 — регулирование Европейского союза, устанавливающее комплексную нормативную базу для криптоактивов и поставщиков услуг, связанных с криптоактивами |
| Регулятор | Компетентный орган, отвечающий за надзор и регулирование финансовых услуг, например Česká národní banka (CNB) для поставщиков услуг по криптоактивам в рамках MiCA |
| TON | [Toncoin (TON)](https://ton.org/) — нативная криптовалюта сети [The Open Network (TON)](https://ton.org/), децентрализованного блокчейна, созданного для быстрых транзакций и удобной интеграции с экосистемой [Telegram](https://telegram.org/) |
| Solana | Высокопроизводительная блокчейн-платформа, поддерживающая смарт-контракты и децентрализованные приложения, с SOL в качестве нативной криптовалюты и поддержкой стейблкоинов вроде USDC и USDY |
| Gas | Комиссия за транзакцию, необходимая для выполнения операций в блокчейн-сети и используемая для компенсации валидаторам за обработку и подтверждение транзакций |
| Validator | Участник сети, отвечающий за проверку и подтверждение транзакций в блокчейн-сети |
| Backoffice | Внутренняя административная система компании, используемая для управления операциями, мониторинга транзакций, проведения compliance-проверок и ведения клиентских записей |
| Spending account | Аккаунты в Holders, предназначенные для привязки карт и совершения покупок |
| Savings account | Балансы подключенного кошелька в разных валютах, используемые для хранения средств |
| Changelly | Сервис обмена криптовалют, интегрированный в Holders для пополнения счетов популярными стейблкоинами |
| USDT | Tether [USDt (USDT)](https://tether.to/en/) — стейблкоин, разработанный Tether, основанный на блокчейн-технологии и привязанный к доллару США в соотношении 1:1. Был создан, чтобы объединить стабильность традиционных денег с удобством и скоростью криптовалютных транзакций. |
| USDC | [USDC](https://www.circle.com/usdc), сокращение от USD Coin, — стейблкоин, созданный в 2018 году и предназначенный для поддержания стабильной стоимости за счет привязки к резервному активу. В случае USDC это доллар США в соотношении 1:1, то есть каждый токен может быть обменян на один доллар США или эквивалентный актив из резерва. |
| USDY | [Ondo US Dollar Yield (USDY)](https://ondo.finance/usdy) — токенизированный финансовый инструмент, который объединяет удобство использования стейблкоина с доходностью от сверхнадежных казначейских облигаций США и банковских депозитов. В первую очередь он рассчитан на инвесторов вне США. |
| Controller | Компонент в архитектуре системы, отвечающий за управление взаимодействием с блокчейном, обработку транзакций и операции со смарт-контрактами |
| Triple-A | Платежный партнер, используемый Holders для обработки SEPA и SWIFT переводов и ручной обработки фиатных транзакций через агентов поддержки |
| IBAN | International Bank Account Number — стандартизированный формат идентификации банковских счетов, используемый в SEPA-переводах и международном банкинге |
| Treasure wallet | Корпоративные криптовалютные кошельки, используемые компанией для управления и хранения цифровых активов в операционных целях |
| Account brand | Идентификатор, указывающий источник создания аккаунта в системе |
| Wallester | Партнер-эмитент карт, предоставляющий платежные карточные сервисы и обрабатывающий карточные транзакции для пользователей Holders |
| KYC | Know Your Customer — процедуры идентификации личности, обязательные для всех пользователей перед доступом к операциям с криптоактивами, которые выполняются внешними провайдерами верификации, например Sumsub |
| AML | Anti-Money Laundering — меры compliance и системы мониторинга, используемые для выявления и предотвращения отмывания денег, включая screening транзакций и оценку рисков |
| Apple Pay | Мобильный платежный сервис Apple, который позволяет пользователям оплачивать покупки с помощью устройств Apple и требует специальных сертификатов для интеграции |
| Google Pay | Мобильный платежный сервис Google, который позволяет выполнять бесконтактные платежи через Android-устройства и также требует специальных сертификатов для интеграции |
| Bank statement | Выписка по счету — документ, отражающий все операции по счету клиента за выбранный период в валюте счета: входящие транзакции, например возвраты и депозиты, и расходы, например платежи |
| Account ownership certificate | Сертификат подтверждает права собственности конкретного лица на децентрализованные аккаунты в системе Holders |
| Travel Rule | [Travel Rule](https://www.fatf-gafi.org/en/publications/Fatf-recommendations/Fatf-recommendations.html) — AML-требование, согласно которому переводы между финансовыми учреждениями, такими как банки, криптовалютные биржи и другие, должны сопровождаться базовой информацией об отправителе и получателе, включая имя, номер счета или адрес, а в некоторых случаях адрес проживания и другие данные |

# Trust

| Term | Definition |
| :--- | :--- |
| Trust | Юридическая конструкция, при которой settlor передает активы trustee для управления в интересах beneficiaries в соответствии с условиями trust agreement |
| Vesting | Постепенное приобретение прав на активы, например акции, опционы или токены, по графику или при выполнении определенных условий |
| Settlor | Учредитель траста — тот, кто вносит активы |
| Trustee | Лицо или компания, управляющие трастом в соответствии с уставом |
| Protector | Контролер trustee, который может согласовывать решения, но не должен иметь прямой контроль, иначе возникают налоговые риски |
| Beneficiary | Лицо, получающее выгоды от траста |
| Vested interest | Безусловное право beneficiary на капитал или доход. Если оно существует, обычно не возникает налога на распределение капитала |
| Corpus / Principal / Capital | Основное тело траста, то есть первоначальные активы |
| Income | Доход, который получает траст, например проценты, прибыль или yield |
| Distribution | Распределение в пользу beneficiary — может происходить либо из капитала, либо из дохода |
| Deed of trust | Основной документ, то есть "устав" траста, в котором все это фиксируется |

# Движение средств

| Term | Definition |
| :--- | :--- |
| Authorization | Процесс предварительной проверки и временной блокировки средств на счете клиента для резервирования суммы под будущую операцию. Подтверждает достаточность баланса у плательщика и дает право списать средства в течение определенного времени |
| Transaction | Отдельная операция, меняющая состояние платежной системы: перевод денег, платеж, возврат или запись о транзакции. Включает отправителя, получателя, сумму, metadata и подтверждение |
| Clearing | Процесс сверки, проверки и расчета взаимных обязательств между участниками на основе набора авторизаций и транзакций. Объединяет операции за период, исправляет расхождения и определяет итоговые суммы к списанию |
| Rollup | Механизм объединения нескольких транзакций в один пакет для оптимизации обработки и снижения комиссий при взаимодействии с блокчейном |
| Partial clearing | Ситуация, когда исполняется только часть обязательств или транзакций из-за нехватки ликвидности или поэтапного исполнения контракта |
| Over-clearing | Случай, когда сумма клиринга превышает сумму, зарезервированную на контракте клиента, из-за особенностей работы платежной системы |
| Reconciliation | Процедуры сравнения данных между разными системами для обеспечения корректности финансовых операций и выявления расхождений |
