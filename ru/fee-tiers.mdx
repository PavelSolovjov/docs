---
title: "Уровни комиссий"
---

Это настраиваемые на уровне платформы тарифные схемы, которые назначаются мерчантам. Хранятся в `fee_tiers` (без `instance_id`, то есть глобально для всей платформы).

```text
interface FeeConfig {
  creation_fee_pct: number;           // например, 2.0
  creation_fee_flat: number;          // например, 0.25 USDC
  creation_fee_min: number;           // например, 0.25 USDC
  claim_fee_pct: number;              // например, 0.0
  claim_fee_flat: number;             // например, 0.0
  changelly_markup_pct: number;       // например, 0.5
  bridge_developer_fee_pct: number;   // например, 1.0
  // Планируемые поля для distribution:
  rebate_pct: number;                 // например, 1.5
  rebate_volume_tiers: VolumeTier[];  // [{threshold_usdc: 50000, rebate_pct: 2.0}]
  rebate_settlement_delay_days: number; // например, 7
}
```

Уровни комиссий управляются администратором платформы через вкладку **System** (`AdminFeeTiersTab`).
