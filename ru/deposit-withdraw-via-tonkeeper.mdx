# Что такое Tonkeeper

[Tonkeeper](https://tonkeeper.com/) — это мобильный некостодиальный криптовалютный кошелек, предназначенный для работы с блокчейном [TON (The Open Network)](https://ton.org/en) и [Tron, где поддерживается только USDT (TRC-20)](https://tron.network/).\
Tonkeeper поддерживает один пул Ton Whales — `Tonkeeper`.

# Требования перед началом

1. Минимальная сумма для отправки средств составляет 50 TON для всех пулов, кроме ликвидного, где минимальная сумма равна 1 TON.
2. Tonkeeper должен быть установлен на мобильном устройстве.
3. Нужно заранее убедиться, что у вас есть средства для оплаты комиссии за вывод. Общая стоимость газа для операции вывода может достигать 0.4 TON, поэтому рекомендуется держать такую сумму на балансе кошелька.
4. Запрос на вывод можно сделать только с адреса кошелька, с которого был отправлен стейк. При потере доступа к кошельку восстановить средства будет невозможно.

# Когда начисляются награды

Награды зачисляются на стейкинговый баланс после завершения каждого полного цикла, в котором участвовали ваши средства.\
**Пример расчета времени начисления:**\
Если вы отправили средства в стейкинг 1-го числа, а текущий стейкинговый цикл заканчивается 2-го числа в 18:00, то:

- ваши средства будут приняты пулом и начнут участвовать в стейкинге со 2-го числа в 18:00,
- первое начисление прибыли произойдет в конце следующего полного цикла, то есть 4-го числа в 06:00, через 36 часов после начала участия в стейкинге.

# Пополнение через Tonkeeper

1. На главной странице кошелька нажмите кнопку Stake.
2. Укажите сумму для отправки в стейкинг и выберите пул Ton Whales, то есть Tonkeeper Queue 1 или 2. Минимальная сумма составляет 50 TON.

# Вывод средств через Tonkeeper

1. На главной странице кошелька выберите пул, из которого хотите вывести средства, и нажмите на него. Пулы отображаются в списке токенов.
2. Нажмите кнопку "Unstake".
3. Укажите сумму, которую хотите вывести из стейкинга.
4. Подтвердите операцию вывода. Система создаст запрос на вывод токенов из стейкинга. За эту операцию взимается комиссия 0.2 TON. Неиспользованная часть комиссии будет возвращена после обработки запроса.
5. После завершения текущего цикла токены появятся на главном экране кошелька со статусом, который указывает на готовность к выводу. Нажмите на соответствующую карточку и подтвердите транзакцию, чтобы завершить процедуру вывода.
6. Средства поступят на баланс кошелька в течение нескольких минут.
