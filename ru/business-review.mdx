Whales AG — швейцарская компания, которая создает международную систему криптоплатежей через управляемую сеть дочерних компаний. В эту сеть входят региональные VASP (Virtual Asset Service Providers), работающие в соответствии с местным законодательством в странах с понятным регулированием криптоактивов, а также отдельные компании для разработки (Software House) и управления правами на технологии (IP Box). Whales AG управляет всей группой компаний, привлекает крупных инвесторов и выстраивает долгосрочные отношения с акционерами на основе полной прозрачности и швейцарской надежности.

# Миссия Whales

Миссия Whales Corp — объединять людей и компании из разных стран и защищать их право свободно пользоваться цифровым долларом без дискриминации, границ и банковских ограничений.

# Видение Whales

Мир, в котором люди и компании из любой страны свободно взаимодействуют друг с другом в цифровых долларах через единую платформу без финансовых посредников.\
Смарт-контракты обеспечивают безопасность, прозрачность и автоматическое исполнение договоренностей, а кошелек (private key) становится цифровым паспортом участника.

# Базовые ценности

**Честность, открытость, прозрачность** во всех аспектах работы.

# История

**2021**

- Команда впервые познакомилась с блокчейном [TON (The Open Network)](https://ton.org), изначально разработанным Telegram как масштабируемая децентрализованная платформа
- Создан майнер, который впервые позволил эффективно добывать токены TON с помощью графических процессоров (GPU)
- Запущен первый и крупнейший в мире майнинговый пул
- Основан первый и крупнейший в мире майнинговый пул для сети TON, что заложило основу для дальнейшего развития экосистемы и холдинга

**2022**

- Запущен собственный криптовалютный кошелек [Tonhub](https://gettonhub.com), ставший важным инструментом взаимодействия пользователей с блокчейном TON
- Разработан и внедрен [первый в мире смарт-контракт для стейкинга токенов TON](https://github.com/tonwhales/ton-nominators)
- Создан [первый стейкинг-пул](https://tonwhales.com/staking) в экосистеме, позволивший пользователям получать пассивный доход от владения токенами TON

**2023**

- Началась активная работа над проектом [Holders](https://holders.io)
- Разработана первая версия [смарт-контракта в блокчейне TON](/holders/product-review/accounts/ton-and-usdt-smart-contracts) для выпуска и управления банковскими картами
- Поданы необходимые документы в международную платежную систему [VISA](https://visa.com) для получения crypto approval
- Начались переговоры с первыми стратегическими партнерами для организации KYC и выпуска карт

**2024**

- Получено официальное разрешение от [VISA](https://visa.com) на работу с криптоактивами
- Реализована [децентрализованная система счетов](/holders/product-review/accounts-and-smart-contracts/Accountssmart-contractsoverview), предоставляющая пользователям полный контроль над своими средствами
- Подписано стратегическое соглашение с финтех-компанией [Wallester](https://wallester.com) на выпуск первых некастодиальных банковских карт для европейских пользователей
- Выполнена глубокая интеграция платформы Holders с кошельком [Tonhub](https://gettonhub.com), создавшая единую экосистему для управления криптоактивами
- Разработан и внедрен [контракт для поддержки платежей в стейблкоине USDT](/holders/product-review/accounts/ton-and-usdt-smart-contracts) в сети TON
- Заключено соглашение с [Triple A](https://triple-a.io), чтобы предоставить пользователям возможность выполнять традиционные банковские переводы [SEPA и SWIFT](/holders/product-review/accounts/account-operations) со своих криптосчетов
- Получена сертификация [Apple Pay](https://apple.com/apple-pay) и [Google Pay](https://pay.google.com) для прямого добавления карт в мобильные кошельки
- Расширена поддержка криптовалют: в платформу Holders добавлен USDC в сети [Solana](https://solana.com), а в Tonhub — поддержка SOL
- Начата разработка Telegram-бота @card для упрощения управления картами через мессенджер Telegram
- Открыты первые партнерские стейкинг-пулы для популярных кошельков [Tonkeeper](https://tonkeeper.com) и платформы ePN

**2025**

- Добавлена возможность пополнять счета через широкий набор популярных блокчейнов благодаря партнерству с обменным сервисом [Changelly](https://changelly.com)
- Разработан специализированный [смарт-контракт для создания vesting-счетов](/holders/product-review/trust-and-vesting), обеспечивающих постепенную разблокировку токенов
- Начато внедрение искусственного интеллекта в пользовательский интерфейс платформы Holders для улучшения пользовательского опыта
- Проведена радикальная перестройка бизнес-подхода и полное обновление бизнес-команды
- Подана заявка на лицензию [MICA (Markets in Crypto-Assets)](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32023R1114) — новый европейский регуляторный стандарт для криптоактивов
- Сервис [Changelly](https://changelly.com) интегрирован напрямую в кошелек Tonhub для мгновенного обмена криптовалют
- Реализован инновационный сервис Post Cash для создания чеков в стейблкоинах
- Заключены соглашения и запущены стейкинг-пулы для крупных институциональных партнеров [Ledger](https://ledger.com) и [P2P](https://p2p.org)
