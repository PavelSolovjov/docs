---
title: "Аннулирование инвойса"
---

```text
UPDATE invoices SET status='void', void_reason=$reason
WHERE id=$id AND instance_id=$instanceId AND status != 'void'
```

**Политика**: аннулирование используется для ошибок до оплаты. Номер инвойса выводится из обращения и больше никогда не переиспользуется. Для исправлений после оплаты следует использовать кредит-ноту (планируется, см. §14).
