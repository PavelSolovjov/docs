# Что такое [tonwhales.com](http://tonwhales.com)

Сайт [tonwhales.com](http://tonwhales.com) предоставляет [веб-интерфейс для стейкинга](https://tonwhales.com/staking) и аналитики токена [TON](https://ton.org/) по всем пулам Ton Whales, без необходимости устанавливать дополнительное программное обеспечение. Сайт поддерживает прямое подключение кошельков через технологию [TON Connect 2.0](https://docs.ton.org/develop/dapps/ton-connect/overview).\
На сайте доступны следующие разделы:

- Staking — информация обо всех активных стейкинг-пулах, интерфейс для отправки и вывода стейков, рейтинги держателей по различным пулам.
- Validator statistics — актуальная информация о текущем составе валидаторов TON.
- Pool comparison — возможность сравнивать разные пулы по доходности.
- Explorer — инструмент для отслеживания транзакций в [блокчейне TON](https://ton.org/).
- Tonhub — раздел с полезными утилитами для кошелька Tonhub.
- Club — раздел, посвященный [клубу whale NFT](https://getgems.io/collection/EQDvRFMYLdxmvY3Tk-cfWMLqDnXF_EclO2Fp4wwj33WhlNFT).

# Пулы на [tonwhales.com](http://tonwhales.com)

- **Nominators** — [первый собственный пул](https://tonwhales.com/staking/pool/nominators). Техническую поддержку инфраструктуры обеспечивает команда Whales. Пул работает в открытом режиме и доступен всем пользователям. Комиссия пула составляет 25%.
- **Club** — приватный пул для держателей [whale NFT](https://getgems.io/collection/EQDvRFMYLdxmvY3Tk-cfWMLqDnXF_EclO2Fp4wwj33WhlNFT). Комиссия составляет 18%.
- **Tonkeeper** — партнерский пул с [некостодиальным кошельком Tonkeeper](https://tonkeeper.com/). Открытый доступ, комиссия составляет 25%.
- **Whales Liquid** — ликвидный пул, который выпускает токены wsTON вместо блокировки средств. Курс wsTON растет пропорционально доходности стейкинга.
- **Team** — приватный пул для команды Whales и топ-15 участников NFT-клуба. Комиссия составляет 5%.
- **P2P** — открытый пул, запущенный в партнерстве с международным стейкинг-провайдером [P2P.org](http://P2P.org). Комиссия пула составляет 15%.
- **Ledger** — открытый пул, запущенный в партнерстве с холодным кошельком [Ledger](https://www.ledger.com/). Комиссия пула составляет 20%.

# Требования перед началом

1. Минимальная сумма для отправки средств составляет 50 TON для всех пулов Ton Whales и 10 TON для P2P и Ledger, кроме ликвидного пула, где минимальная сумма равна 1 TON.
2. На мобильном устройстве должен быть установлен кошелек Tonhub.
3. Необходимо заранее убедиться, что у вас есть средства для оплаты комиссии за вывод. Общая стоимость газа для операции вывода может достигать 0.4 TON, поэтому рекомендуется держать такую сумму на балансе кошелька.
4. Запрос на вывод можно сделать только с адреса кошелька, с которого был отправлен стейк. При потере доступа к кошельку восстановить средства будет невозможно.
5. Отправка средств с кастодиальных кошельков или криптовалютных бирж строго запрещена. При нарушении этого требования средства будут безвозвратно утеряны.

# Когда начисляются награды

Награды зачисляются на стейкинговый баланс после завершения каждого полного цикла, в котором участвовали ваши средства.\
**Пример расчета времени начисления:**\
Если вы отправили средства в стейкинг 1-го числа, а текущий стейкинговый цикл заканчивается 2-го числа в 18:00, то:

- ваши средства будут приняты пулом и начнут участвовать в стейкинге со 2-го числа в 18:00,
- первое начисление прибыли произойдет в конце следующего полного цикла, то есть 4-го числа в 06:00, через 36 часов после начала участия в стейкинге.

# Пополнение через сайт

1. Перейдите [на страницу стейкинга](https://tonwhales.com/staking) и выберите пул, в который хотите отправить средства, нажав на его изображение. Обратите внимание, что у пулов Team и Club есть ограничения, поэтому перед отправкой средств внимательно ознакомьтесь с их условиями.
2. Если вы используете мобильный кошелек с поддержкой TON Connect, подключите его к сайту с помощью кнопки Connect wallet. Это упростит процесс отправки средств.
3. Выберите одну из очередей пула и нажмите Stake. Сравните доходность очередей и, если она одинаковая, выберите ту, где стейкинговый цикл закончится раньше: так вы начнете получать прибыль быстрее. Подробнее об очередях.
4. Введите сумму, которую хотите отправить в стейкинг, и выберите способ совершения транзакции:

# Вывод через [tonwhales.com](http://tonwhales.com)

1. Перейдите в [раздел стейкинга](https://tonwhales.com/staking) сайта [tonwhales.com](http://tonwhales.com).
2. Если вы используете мобильный кошелек с поддержкой TON Connect, подключите его к сайту через кнопку Connect wallet. Это упростит процесс вывода, поскольку сайт сразу покажет, в каком пуле находятся ваши средства.
3. Выберите пул и очередь, из которых хотите вывести средства.
4. Нажмите кнопку Withdraw.
5. Укажите сумму, которую хотите вывести. Для вывода, как и для пополнения, доступны два варианта:

# Период cooldown

В течение первых двух часов каждого стейкингового цикла действует упрощенный период, то есть cooldown, когда валидаторы находятся в режиме ожидания. В этот промежуток пользователи могут мгновенно выполнять операции пополнения и вывода, не дожидаясь завершения цикла. Когда период cooldown активен сразу в обоих пулах, пользователи могут переводить средства между пулами без потери дохода за текущий цикл. Кроме того, операции вывода в этот период выполняются одной транзакцией вместо стандартных двух.
