# Выпуск карты

Чтобы выпустить новую карту, перейдите в режим Cards и воспользуйтесь одним из следующих способов:

- Нажмите на силуэт карты со значком `+` на карточке аккаунта, для которого хотите выпустить карту, и следуйте инструкции.

<img
  src="/images/2026-02-2414.01.24.jpg"
  alt="2026 02 2414 01 24"
  title="2026 02 2414 01 24"
  className="mx-auto"
  style={{ width:"35%" }}
/>

- Нажмите на карточку аккаунта, для которого хотите выпустить карту, и следуйте дальнейшим шагам в интерфейсе.

# Скрытие аккаунтов

Аккаунт можно временно скрыть из списка в режиме Cards, если он не используется. Для этого сделайте свайп влево по нужной карточке аккаунта и нажмите на иконку с зачеркнутым глазом.

<img
  src="/images/2026-02-2414.01.27.jpg"
  alt="2026 02 2414 01 27"
  title="2026 02 2414 01 27"
  className="mx-auto"
  style={{ width:"35%" }}
/>

Чтобы вернуть отображение аккаунта, прокрутите интерфейс вниз и нажмите кнопку "Show". Затем снова сделайте свайп влево по скрытому аккаунту и нажмите на иконку глаза — аккаунт вернется в активный список.
