---
title: "Пользовательские настройки в Tonhub"
---

В Tonhub пользователь может менять внешний вид приложения, язык, валюту отображения, формат адресов, параметры спам-фильтра, настройки безопасности и персональные данные для каждого кошелька. Ниже перечислены **все доступные настройки**, где они находятся и как сохраняются.\
**Где открыть настройки:** главный экран → вкладка `Settings`. Часть опций применяется ко всему приложению, а часть относится только к выбранному кошельку, например имя, аватар и цвет задаются в настройках кошелька или по нажатию на карточку кошелька.

# Тема (light / dark / system)

**Экран:** `Settings` → `Theme`.\
**Опции:**

- **Light** — светлый фон и темный текст.
- **Dark** — темный фон и светлый текст.
- **System** — автоматически следует системной теме устройства, светлой или темной, в зависимости от настроек ОС.

**Где хранится:** локально на устройстве, ключ `themeStyle` в хранилище приложения. При смене темы также обновляется цвет navigation bar, `NavBar`.\
**Значение по умолчанию:** `System`.

# Язык интерфейса

**Экран:** `Settings` → `Language`.\
**Доступные языки:**

- English
- Русский
- Українська
- Español
- Deutsch
- Français
- Italiano
- Português

Коды: `en`, `ru`, `uk`, `es`, `de`, `fr`, `it`, `pt`. Список задается в приложении через `langResources`. При первом запуске, если язык не выбран, может использоваться системный язык устройства, `getLocales()[0].languageCode`.\
**Где хранится:** локально, ключ `languageState`. После смены языка приложение перезапускается, чтобы применить переводы ко всем экранам.\
**По умолчанию:** системный язык или ранее сохраненное значение.

# Поисковая система (в браузере)

**Экран:** `Settings` → `Search engine`.\
**Опции:**

- **Google** — поиск через Google при вводе запроса в адресную строку встроенного браузера приложения, `WebView`.
- **DuckDuckGo** — поиск через DuckDuckGo.

**Где хранится:** в общем хранилище приложения, ключ `searchEngine`. Используется при подстановке search URL, когда пользователь вводит текст в адресную строку встроенного браузера.\
**По умолчанию:** `DuckDuckGo`.

# Основная валюта (для отображения сумм)

**Экран:** `Settings` → `Primary currency`.\
**Опции:** `USD`, `EUR`, `RUB`, `GBP`, `CHF`, `CNY`, `KRW`, `IDR`, `INR`, `JPY`. В интерфейсе отображаются символ и название валюты, например `U.S. Dollar` для `USD`.\
**Где хранится:** в **облачном хранилище Tonhub**, ключ `primaryCurrency-v1`, привязан к устройству или аккаунту. Это позволяет сохранить выбор валюты при переустановке приложения, если используется тот же ключ.\
**По умолчанию:** `USD`.\
**Использование:** балансы, суммы транзакций, комиссии и fiat-эквиваленты показываются в выбранной валюте, с использованием exchange rates с backend.

# Формат TON-адреса (bounceable / non-bounceable)

**Экран:** `Settings` → `New address format`.\
**Опции:**

- **Bounceable.** Если получатель — контракт, который еще не задеплоен или не может обработать запрос, TON возвращается за вычетом комиссии за обработку.
- **Non-bounceable.** Если контракт не существует, TON будет потерян, то есть израсходован на сетевые комиссии.

**Где хранится:** локально, ключ `bounceableWalletFormat`. Влияет на то, как TON-адреса отображаются и копируются, например при получении, в контактах, в данных для dApps и так далее.\
**По умолчанию:** `true`, то есть bounceable. В коде для некоторых новых сценариев non-bounceable может использоваться по умолчанию, но фактическое значение берется из хранилища.

# Спам-фильтр

**Экран:** `Settings` → `Spam filter`.\
**Настройки:**

- **Minimum amount:** TON-транзакции с суммой **ниже** заданного порога, в TON, автоматически помечаются как spam. Пользователь вводит значение в TON, а сохраняется оно в nano-TON. Используется только для **TON**, включая TON tokens; Solana transactions по этому правилу не маркируются.
- **Don't show comments on SPAM transactions:** переключатель. Если включен, comments, то есть payload, у транзакций, помеченных как spam, не показываются в списке.
- **Manual list, deny list:** адреса, которые пользователь вручную добавил в "spam". Такие адреса показываются с spam badge при отправке, но **отправка не блокируется**, пользователь может подтвердить перевод. На экране spam filter можно посмотреть список и удалить адреса из блокировки, то есть `unblock`.

**Где хранится:** minimum amount и флаг "don't show comments" — локально, либо в общем хранилище приложения; deny list хранится в address book context, в contacts/deny list. Синхронизация deny list между устройствами зависит от реализации, например через cloud storage по ключу.\
**Примечание:** пометка "spam" по сумме и deny list применяется только к операциям в TON network и к отображению tokens. Solana transactions через этот фильтр не проходят.

# Настройки кошелька (имя, аватар, цвет)

**Экран:** нажатие на карточку выбранного кошелька на главном экране или в switcher → `Wallet settings`, либо экран редактирования кошелька.\
**Параметры, для каждого кошелька отдельно:**

- **Name:** произвольное имя кошелька, текст. Показывается на карточке и в списке кошельков. Для Ledger можно задать имя устройства.
- **Avatar:** выбор изображения аватара из набора, по индексу. Для Ledger avatar не меняется и остается `null`.
- **Color:** выбор цвета из palette, индекс в массиве цветов. Используется для оформления карточки кошелька.

**Где хранится:** в общем хранилище приложения, ключ `walletsSettings`; значение имеет вид `{ [addressKey]: { name, avatar, color } }`. Ключ привязан к адресу кошелька либо к Ledger identifier. Данные локальные.\
**По умолчанию:** имя — это `Wallet N`, где `N` номер в списке, либо имя Ledger; avatar и color вычисляются детерминированно из address hash, если пользователь их не менял.

# Безопасность (PIN, биометрия, блокировка приложения)

**Экран:** `Settings` → `Security`. Доступно только для обычных wallets, не для Ledger-only сценария.\
**Настройки:**

- **PIN code:** установка, изменение или удаление PIN для разблокировки доступа к ключам и подтверждения операций. Статус, установлен или нет, хранится в secure storage, то есть SecureStore или Keychain.
- **Biometrics:** включение или отключение входа и подтверждения операций через Face ID на iOS или отпечаток пальца / распознавание лица на Android. Доступно только если PIN уже задан. Статус хранится в приложении, `useBiometricsState`.
- **Lock app with auth:** если включено, приложение запрашивает PIN или biometrics при возврате из background либо при открытии. Это отдельный toggle в разделе `Security`.

**Где хранится:** PIN и keys — в secure storage ОС, то есть Keychain или Keystore; флаги `use biometrics` и `lock on exit` — в настройках приложения локально.\
**Примечание:** эти настройки не конфигурируют backend, они влияют только на локальную разблокировку и подтверждение операций на устройстве.

# Контакты (адресная книга)

**Экран:** `Settings` → `Contacts`.\
**Что это:** список сохраненных contacts, имя и TON- или Solana-адрес. Пользователь может добавлять, редактировать и удалять contacts. При переводе выбор контакта подставляет адрес и показывает имя; contacts также используются для пометки "known wallet" и связки с deny list, если адрес добавлен в spam, он остается в contacts/deny list с соответствующей пометкой.\
**Где хранится:** в address book context, `AddressBookContext`; данные могут сохраняться локально и синхронизироваться при необходимости, в зависимости от реализации. Deny list, то есть manual spam, привязан к этому же разделу.

# Другие настройки

Раздел `Settings` также включает пункты, которые не являются пользовательскими "опциями", а ведут на важные экраны:

- **Key backup** — переход к seed phrase и инструкциям по резервному копированию.
- **Holders accounts** — переход в Holders, то есть cards и accounts; отображается, когда продукт Holders доступен.
- **Legacy wallet migration** — показывается, если на старых адресах есть balance; ведет на migration.
- **Support** — ссылки на Telegram, форму поддержки, Holders и Tonhub.
- **Rate app** — переход в app store для оценки и отзыва.
- **Terms of Service** и **Privacy Policy** — открытие соответствующих страниц.
- **Delete account / disconnect wallet** — удаление wallet из приложения или отключение Ledger, в зависимости от контекста.
- **Developer tools** — появляется после нескольких нажатий на версию приложения; дает доступ к debug screens, logs, storage и другим инструментам.
