Интерфейс биллинга находится в `/instance/dashboard` → `InstanceDashboard.tsx`, вкладка `Revenue`.

## Структура вкладки Revenue

Используется **ручная навигация кнопками на `useState`**. Вложенный Radix `<TabsList>` не рендерится из-за конфликта React context, подробнее см. `CLAUDE.md`, раздел `Known Caveats`.

- Вкладка `Revenue`
- Подвкладка `Overview`
- Подвкладка `Invoices`
- Подвкладка `Export`
- Подвкладка `Fee Ledger`

### Overview

- KPI-карточки, `Collected / Pending / Failed / Gross`
- таблица `тип комиссии × статус`
- таблица `собрано / в ожидании по каждому merchant`

### Invoices

- форма `Generate`
- список инвойсов
- диалог деталей
- позиции инвойса
- действие `Finalize`
- действие `Void`

### Export

- диапазон дат
- `Download CSV`

### Fee Ledger

- фильтр по статусу
- пагинированная таблица, 50 записей на страницу

## Запланированные дополнения

- Подвкладка **Settlements** — список settlement statements по merchant, действия `generate` и `mark-paid`
- Подвкладка **Rebates** — список rebate notices и статусы `paid / pending`

## Цветовые статусы

| Статус | Цвет | Значение |
| :-- | :-- | :-- |
| `draft` | gray | Создан, но еще не выпущен |
| `issued` | blue | Формально выпущен, ожидает оплаты |
| `void` | red | Отменен |
| `unpaid` | yellow | Оплата ожидается |
| `paid` | green | Подтвержден как оплаченный |
| `overdue` | red | Просрочен |
| `waived` | gray | Списан решением администратора |
| `pending` | yellow | Rebate запланирован, но еще не выплачен |

## Контроль доступа

Вкладку `Revenue` могут просматривать `owner`, `admin`, `finance`, `viewer`.

Действия `Generate`, `Finalize`, `Void`, `Mark Paid` доступны только для `owner` и `admin`, плюс проверка безопасной сессии на серверной части.
