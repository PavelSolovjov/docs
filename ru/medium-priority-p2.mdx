title: "Средний приоритет (P2)"
---

| Пробел | Последствие | Решение |
| :-- | :-- | :-- |
| Нет reconciliation-job | Невидимый drift в ledger | Ночной reconciliation query \+ <br />alert |
| Нет per-cheque invoice <br />line items | Все агрегировано только по типу комиссии | Добавить опцию детальных line items |
| Нет auto-upgrade для volume tier | `volume_threshold_monthly` <br />не используется | Ежемесячная проверка объема \+ <br />назначение tier |
| Нет breakage fee | Истекшие профондированные чеки <br />остаются без обработки | Фаза 2: механизм возврата фондов |
| Нет учета agent commission | Наценка merchant для конечного клиента <br />не отслеживается | Добавить `agent_commission_pct` <br />в `merchants` |
| `merchant_type` не смоделирован | Нет различия между agent и reseller | Миграция `042` |
| Не enforced immutability на уровне БД | Сейчас только app-level логика | PostgreSQL rules для <br />`fee_ledger` |
