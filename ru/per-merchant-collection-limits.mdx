---
title: "Лимиты сбора по merchant"
---

Проверяются в `api/fees.ts`, функция `checkMerchantLimits()`:

| Лимит | Значение по умолчанию | Как проверяется |
| :-- | :-- | :-- |
| На одну операцию | 10 USDC | Проверка в памяти |
| Дневной | 500 USDC | `SUM`-запрос по `fee_ledger WHERE created_at >= today` |
| Месячный | 10,000 USDC | `SUM`-запрос по `fee_ledger WHERE created_at >= month_start` |

Превышение лимита не блокирует работу, чек продолжает работать, а запись о комиссии остается в статусе `pending` для ручной проверки.
