# Пополнение, то есть отправка средств в стейкинг

Пополнение ликвидного пула выполняется двумя способами:

- **Покупка токенов на DEX.** Пользователь может приобрести wsTON на децентрализованной бирже по [этой ссылке](https://app.dedust.io/swap/TON/wsTON), совершив обмен в паре TON/wsTON. Это самый простой способ, однако при обмене значительных сумм TON курс будет менее выгодным по сравнению с прямым входом в стейкинг. Например, при обмене 1 000 TON через DEX пользователь получит 917.04 wsTON, а при отправке в стейкинг — 926.4 wsTON.
- **Отправка TON в стейкинг через интерфейс Tonhub или сайт [tonwhales.com](http://tonwhales.com).** Этот способ выгоднее первого, поэтому ниже он разобран подробнее.

## Пополнение через сайт [tonwhales.com](http://tonwhales.com)

1. Перейдите на страницу https://tonwhales.com/staking/liquid и нажмите кнопку "Stake".
2. В открывшемся диалоговом окне выполните следующие действия:

- Укажите количество TON, которое нужно отправить в стейкинг.

  - При подключении кошелька подтвердите транзакцию в приложении. Токены wsTON появятся на вашем балансе в течение нескольких минут.

# Вывод средств из ликвидного стейкинга

Вывод из ликвидного пула также выполняется двумя способами:

- **Продажа токенов на DEX.** Пользователь может продать wsTON на децентрализованной бирже по [этой ссылке](https://app.dedust.io/swap/TON/wsTON), совершив обмен в паре TON/wsTON. Это самый простой способ, однако при обмене значительных объемов TON курс будет менее выгодным по сравнению с выводом из стейкинга. Например, при обмене 1 000 wsTON через DEX пользователь получит 1 065.8 TON, тогда как при выводе из стейкинга — 1 079 TON.
- **Вывод TON из стейкинга через интерфейс Tonhub или сайт [tonwhales.com](http://tonwhales.com).** Этот способ выгоднее первого, поэтому ниже он разобран подробнее.

## Вывод через интерфейс сайта [tonwhales.com](http://tonwhales.com)

1. Перейдите на страницу https://tonwhales.com/staking/liquid и нажмите кнопку "Withdraw".
2. Выберите способ вывода:

- Подключите кошелек Tonhub, отсканировав QR-код, так как подключение выполняется через протокол [Tonconnect](https://github.com/ton-connect). Подтвердите появившуюся транзакцию. После завершения цикла повторите запрос на вывод, и TON поступят на баланс в течение нескольких минут.
- Нажмите "Manual withdraw", чтобы выполнить ручной вывод.

После завершения цикла отправьте еще одну транзакцию на адрес пула с комментарием `Collect`. Для этого запроса также потребуется комиссия 0.2 TON. ## Вывод через интерфейс Tonhub

1. Перейдите в раздел стейкинга, нажав на баннер на главном экране.
2. Выберите пул Whales Liquid и нажмите Withdraw.
3. Укажите сумму для вывода из стейкинга. Для отправки запроса потребуется комиссия 0.2 TON.

4. После завершения цикла на странице пула появятся средства, готовые к выводу. Нужно будет еще раз нажать кнопку вывода. Для отправки второго запроса потребуется комиссия 0.2 TON. Средства поступят на указанный адрес в течение нескольких минут.
