---
title: "Глоссарий"
---

| Термин                   | Определение                                                                                                                                                                                                                                             |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **TON**                  | [Toncoin (TON)](https://ton.org/) - нативная криптовалюта сети [The Open Network (TON)](https://ton.org/), децентрализованного блокчейна, созданного для быстрых транзакций и удобной интеграции с экосистемой [Telegram](https://telegram.org/). |
| **Gas**                  | Комиссия за транзакцию, необходимая для выполнения операций в блокчейн-сети и оплаты работы валидаторов по обработке и подтверждению транзакций.                                                                                                      |
| **Proof-of-Stake (PoS)** | Алгоритм консенсуса, который использует токены как залог вместо вычислительной мощности: валидаторы блокируют свои токены в стейке, чтобы участвовать в создании блоков и получать награды.                                                          |
| **Proof-of-Work (PoW)**  | Алгоритм консенсуса, при котором участники сети соревнуются в решении сложных криптографических задач с помощью вычислительной мощности, чтобы получить право добавить новый блок и получить вознаграждение.                                         |
| **Staking**              | Процесс блокировки токенов для поддержки работы и безопасности сети в обмен на вознаграждение.                                                                                                                                                         |
| **Mining**               | Процесс, при котором компьютеры решают сложные задачи для добавления нового блока в блокчейн. Первый решивший получает вознаграждение в виде криптовалюты и комиссий за транзакции.                                                                  |
| **Validator**            | Узел, то есть сервер, в блокчейне, который проверяет и добавляет блоки, блокируя собственные монеты в качестве залога, то есть stake.                                                                                                                |
| **Nominator**            | Участник, который делегирует свои токены валидатору, чтобы участвовать в стейкинге и получать часть наград.                                                                                                                                            |
| **Staking pool**         | Группа участников, которые объединяют свои TON для совместного стейкинга, чтобы повысить шанс получения награды и снизить порог входа.                                                                                                                |
| **Cycle**                | Фиксированный период в 36 часов, в течение которого валидаторы в [сети TON](https://ton.org/en) подтверждают и производят блоки, после чего награды рассчитываются и распределяются между участниками стейкинга.                                      |
| **Voting**               | Процесс принятия решений валидаторами TON по изменению параметров конфигурации блокчейна, включая количество валидаторов и другие системные настройки.                                                                                               |
| **Queue**                | Независимая группа участников стейкинга внутри одного пула, сформированная для оптимизации пользовательского опыта в двухцикловой системе TON. Каждый staking pool работает с двумя очередями, смещенными на 18 часов.                                |
| **Smart contract**       | Программа, которая автоматически исполняет и обеспечивает выполнение условий соглашения в блокчейне. Ее код хранится и исполняется в сети без посредников по заранее заданным правилам.                                                              |
| **Blockchain**           | Распределенная база данных, состоящая из цепочки блоков, каждый из которых содержит криптографическую ссылку на предыдущий.                                                                                                                            |
