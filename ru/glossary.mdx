---
title: "Glossary"
---

| Term                     | Definition                                                                                                                                                                                                                                              |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **TON**                  | [Toncoin (TON)](https://ton.org/) is the native cryptocurrency of [The Open Network (TON)](https://ton.org/), a decentralized blockchain created for fast transactions and convenient integration with the [Telegram](https://telegram.org/) ecosystem. |
| **Gas**                  | Transaction fees required to execute operations on a blockchain network, used to compensate validators for processing and validating transactions                                                                                                       |
| **Proof-of-Stake (PoS)** | A consensus algorithm that uses token collateral instead of computing power: validators lock their tokens as a stake to participate in block production and earn rewards.                                                                               |
| **Proof-of-Work (PoW)**  | A consensus algorithm where network participants compete to solve complex cryptographic puzzles using computing power to gain the right to add a new block and receive a reward.                                                                        |
| **Staking**              | The process of locking tokens to support the operation and security of the network in exchange for rewards.                                                                                                                                             |
| **Mining**               | The process in which computers solve complex problems to add a new block to the blockchain. The first to solve the problem receives a reward in the form of cryptocurrency and transaction fees.                                                        |
| **Validator**            | A node (server) in a blockchain that verifies and adds blocks, locking its own coins as collateral (stake).                                                                                                                                             |
| **Nominator**            | A participant who delegates their tokens to a validator in order to take part in staking and share in the rewards.                                                                                                                                      |
| **Staking pool**         | A group of participants who combine their TON for joint staking to increase the chances of earning rewards and to lower the entry threshold.                                                                                                            |
| **Cycle**                | A fixed time period of 36 hours during which validators in the [TON network](https://ton.org/en) perform block validation and production, after which rewards are calculated and distributed among staking participants.                                |
| **Voting**               | The decision-making process by TON validators to change blockchain configuration parameters, including the number of validators and other system settings.                                                                                              |
| **Queue**                | An independent group of staking participants within a single pool, formed to optimize user experience in TON’s two-cycle system. Each staking pool operates two queues offset by 18 hours.                                                              |
| **Smart contract**       | A program that automatically executes and enforces agreement conditions on a blockchain. Its code is stored and executed on the network, without intermediaries, according to predefined rules.                                                         |
| **Blockchain**           | A distributed database consisting of a chain of blocks, each containing a cryptographic link to the previous one                                                                                                                                        |
