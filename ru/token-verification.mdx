Зеленая галочка в Tonhub показывает, что токен является официальным.

## Как это работает

Приложение проверяет адрес master-контракта токена по специальному списку доверенных контрактов. Если адрес есть в этом списке, рядом с токеном появляется зеленая галочка.\
**Откуда берется список проверенных токенов:**

- встроенные данные приложения,
- обновляемый конфиг из GitHub.

**Зачем это нужно:**\
Галочка помогает убедиться, что перед вами оригинальный токен, а не подделка. У фейковых копий будут другие адреса контрактов, поэтому галочка для них не появится. При этом галочка не гарантирует, что сам токен не был создан в мошеннических целях, и кошелек не несет за это ответственность.

# Как работает верификация токенов

В приложении есть система, которая проверяет, является ли токен настоящим или поддельным. Когда вы видите зеленую галочку рядом с токеном, это означает, что приложение нашло адрес этого токена в специальном списке проверенных токенов.\
Зеленая галочка появляется, если адрес основного контракта токена, то есть его "паспорта" в блокчейне, есть в списке доверенных адресов.

# Откуда берется список проверенных токенов

## Встроенный список популярных токенов

- В самом приложении есть заранее подготовленный список адресов известных токенов. В него входят популярные токены, такие как jUSDT, jUSDC, NOT, USD₮ и другие. Этот список составляется разработчиками вручную.
- Для некоторых специальных токенов, например Ethena USDe, адреса добавляются автоматически.

Встроенный список имеет приоритет: сначала используются эти проверенные токены, а затем к ним добавляются данные из интернета.

## Обновляемый список из интернета

Приложение загружает свежий список проверенных токенов из GitHub. Этот список обновляется отдельно от приложения и содержит новые проверенные токены. В нем есть разделы для mainnet и testnet. В каждом разделе содержатся адреса проверенных токенов и список известных названий токенов.\
Итоговый список = встроенные токены + токены из интернета. Приложение обновляет этот список каждые 5 минут и при каждом открытии.

# Где показывается галочка

- **На иконке токена:** зеленая галочка появляется прямо на изображении токена, если его адрес есть в списке проверенных.
- **Во время переводов:** галочка отображается рядом с названием токена в кошельке и на экранах перевода.
- **Для TON:** основная монета TON всегда показывается с галочкой, так как по умолчанию считается проверенной.

# Запросы на верификацию

Сейчас из-за роста количества мошеннических проектов и краткоживущих токенов было принято решение приостановить процедуру верификации сторонних токенов. Статус верификации присваивается только стейблкоинам и нативным монетам.

# Автоматическая маркировка SCAM

В кошельке реализован механизм автоматического определения мошеннических токенов. Система анализирует ticker токена и сравнивает его с базой известных тикеров. Если тикер присутствует в списке известных, но адрес master-контракта отсутствует в списке проверенных master-адресов, токен автоматически помечается как Scam. В интерфейсе такие токены отображаются с красной меткой SCAM вместо зеленой галочки верификации. Этот механизм защищает пользователей от поддельных токенов, использующих популярные тикеры, например USDT.
