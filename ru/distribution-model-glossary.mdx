---
title: "Глоссарий distribution-модели"
---

| Термин | Определение |
| :-- | :-- |
| **Issuer** | Оффшорная компания, которая создает и владеет batch-партиями чеков |
| **Instance** | Tenant платформы, управляемый бизнес-командой Issuer |
| **Merchant** | Дистрибьютор или агент, который продает чеки конечным клиентам |
| **Agent commission** | Наценка, которую мерчант удерживает сразу из платежа конечного пользователя |
| **Rebate** | Выплата от Issuer мерчанту после settlement, рассчитывается <br />на основе подтвержденного объема |
| **Settlement Statement** | Документ от Issuer мерчанту: сумма, причитающаяся <br />за активированные чеки за период |
| **Agent's Report** | Документ от мерчанта Issuer: сводка продаж и перечислений |
| **Rebate Notice** | Документ от Issuer мерчанту: сумма rebate за период |
| **Platform Invoice** | Документ от оператора платформы оператору инстанса: <br />инфраструктурные комиссии |
| **Face value** | Номинал чека в USDC, то есть "цена" продукта |
| **Settlement currency** | Фиатная или криптовалютная валюта, в которой мерчант рассчитывается с Issuer |
| **FX rate lock** | Обменный курс, фиксируемый на момент выпуска statement, а не на момент оплаты |
| **Contingent liability** | Обязательство мерчанта по уже отгруженным, но еще не активированным чекам |
