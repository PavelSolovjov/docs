## Settlement-период, например ежемесячный

| Этап | Описание |
| :-- | :-- |
| День 1–28 | Merchant активирует чеки, обязательство накапливается |
| День 28 | Период закрывается, администратор генерирует `Settlement Statement` для merchant |
| День 28–35 | Merchant проверяет документ и перечисляет номинал в `settlement_currency` по текущему FX-курсу |
| День 35 | Администратор подтверждает оплату, после чего `settlement_status = paid` |
| День 35\+N | Рассчитывается и выплачивается rebate, где `N = delay_days`, затем формируется `Rebate Notice` |
