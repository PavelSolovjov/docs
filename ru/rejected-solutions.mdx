---
title: "Отклоненные решения"
---

| Решение | Причина |
| :-- | :-- |
| **pdfkit** | Более многословный, чем `pdfmake`; подходит только как запасной вариант, если потребуется более жесткий контроль над layout |
| **Invoice Ninja / Crater** | Основаны на Laravel / PHP, то есть это отдельный стек и слишком тяжелое решение |
| **Kill Bill** | Java enterprise-решение, сильно превышает реальные требования |
| **Puppeteer** | Работает только в Node.js и не запускается в Deno, поэтому вместо него лучше использовать Gotenberg |
