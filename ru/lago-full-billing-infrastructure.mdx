title: "Lago — полная billing-инфраструктура"
---

**GitHub**: [https://github.com/getlago/lago](https://github.com/getlago/lago)\
**License**: AGPLv3 server / MIT JS client\
**Stack**: Rails \+ PostgreSQL \+ Redis \+ Sidekiq \+ Kafka

**Вердикт**: не рекомендуется для встраивания. Слишком тяжелый стек, 6\+ контейнеров. Подходит только если платформа со временем перейдет к event-based metering, то есть к биллингу usage per cheque, и будет разворачиваться как отдельный сервисный стек.

JS-клиент `lago-javascript-client` распространяется по MIT и совместим с Deno через `npm:lago-javascript-client`.
