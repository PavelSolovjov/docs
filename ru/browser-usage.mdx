Браузер в Tonhub — это вкладка на главном экране приложения в режиме Wallet. Он позволяет открывать сайты и dApps (децентрализованные приложения), подключать кошелек через TON Connect, сохранять приложения в раздел `Extensions` и управлять подключениями.

В верхней части экрана браузера находится поисковая строка.

- **Ввод адреса сайта (URL):** введите полный адрес, например `https://app.example.com`, и нажмите `Go` или аналогичную кнопку на клавиатуре. Страница откроется во встроенном браузере приложения. Если адрес не откроется, приложение может показать сообщение об ошибке: неверный URL или недоступность сайта.
- **Ввод поискового запроса:** если вместо URL введен обычный текст, например `TON staking`, приложение отправит запрос в поисковую систему — Google или DuckDuckGo. Какая именно система используется, задается в `Settings -> Search Engine`. Затем откроется страница с результатами поиска.
- **Подсказки:** при вводе под поисковой строкой могут появляться подсказки, включая рекомендованные dApps и веб-результаты. Нажмите на нужную подсказку, чтобы открыть соответствующий сайт.

Страницы открываются во встроенном браузере, WebView, с поддержкой TON Connect: приложение может запросить подключение кошелька и подписание транзакции.

Здесь отображаются приложения, которые вы добавили сами: установленные расширения и сохраненные dApps.

- **How to add:** open the desired site through the search bar (enter URL and navigate). On first opening, the application may suggest installing or adding it — confirm. After that it will appear in the "Extensions" tab.
- **How to remove:** tap on the application and select **"**Revoke Access**"** (or long press on the application card and select revoke). Confirm — the application will disappear from the list. Its access to the wallet will be revoked.

If the list is empty, there will be a message like "No extensions yet" on the screen — add applications through URL search.

## Connections

Here are shown applications to which your current wallet is connected via TON Connect (you previously pressed "Connect" on the site).

- **How to disconnect:** tap on the application and select **"**Revoke Access**"**. Confirm — the application will be disconnected from the wallet and disappear from the connections list for this wallet.

If the list is empty — it means nothing is connected to the selected wallet yet.

# Открытие сайта по QR-коду

- In the top right corner of the browser screen there is a QR code scanning button (scanner icon).
- Tap it, allow camera access if necessary and point the camera at a QR code with a link to a site or dApp. After recognition, the corresponding page will open.

Convenient for quick navigation to links from computer or promotional materials.

# Подключение кошелька к приложению (TON Connect)

1. Open the application site through the search bar or from "Recommended" / "Extensions".
2. On the site, press the **"**Connect Wallet**"** button (or equivalent). A connection request will appear in Tonhub: application name and requested permissions.
3. Confirm the connection — the wallet will be linked to this application. It will appear in the **"**Connections**"** tab.
4. When the application requests signing a transaction or data, a confirmation screen will open in Tonhub. Check the amount, address and details, then confirm or reject the request.

The connected wallet can be disconnected at any time in the "Connections" tab (Revoke Access).
