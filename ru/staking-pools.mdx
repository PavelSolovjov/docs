# Что такое стейкинг-пул

Стейкинг-пул — это сервис [на базе смарт-контракта](/ru/smart-contract-nominators), который позволяет нескольким пользователям объединять свои токены для совместного участия в стейкинге, пропорционально распределять награды в зависимости от вклада каждого участника и не запускать собственный валидатор.\
Стейкинг-пулы Ton Whales делятся на собственные пулы, полностью принадлежащие Ton Whales, и партнерские пулы, которые запускаются совместно с партнерами.

# Партнерские пулы Ton Whales

Партнерский пул — это стейкинг-пул, запущенный совместно с партнером. Обычно Whales запускают и обслуживают всю инфраструктуру пула, а партнер привлекает в него номинаторов, хотя бывают случаи, когда инфраструктура также находится на стороне партнера, а Whales предоставляют только смарт-контракт. Комиссия, полученная от номинаторов в партнерском пуле, делится между Whales и партнером в заранее согласованной пропорции с помощью [DAO-контракта](/ru/smart-contract-dao).

<Info>
  ## Почему партнер не может запустить пул самостоятельно, если контракт с открытым исходным кодом?

  1. Несмотря на открытый исходный код контракта, для его безопасного использования необходимы дорогостоящие аудиты безопасности. Whales предоставляет результаты проведенных аудитов партнерам после подписания соглашения о сотрудничестве.
  2. Стейкер является проприетарным ПО и критически важным компонентом для работы пула. Доступ к исходному коду стейкера предоставляется партнерам только после подписания договора.
  3. Whales оказывает партнерам полную техническую поддержку на всех этапах настройки, развертывания и запуска стейкинг-пулов.
</Info>

# DAO-контракт номинаторов

Децентрализованный [смарт-контракт](/ru/smart-contract-dao) с тремя основными функциями:

- **Голосование по предложениям** — контракт хранит список участников и веса их долей. Любой участник DAO может создать предложение, представляющее собой набор заранее определенных действий. Остальные участники голосуют за или против, отправляя соответствующие сообщения на адрес контракта.
- **Распределение доходов от стейкинга** — весь поступающий доход распределяется между участниками DAO согласно заранее установленным долям.
- **Управление стейкинг-пулом** — контракт может вносить изменения в параметры работы пула, если соответствующее предложение было одобрено голосованием.

Контракт разворачивается до запуска партнерского пула, и все последующие изменения параметров пула выполняются исключительно через него, что обеспечивает честность процедур и полную прозрачность операций.

## Как работает проверка NFT-кошелька

Когда пользователь инициирует стейкинг в клубном пуле, стейкер сравнивает адрес пользователя с адресами владельцев NFT из собственного API.\
Если адрес владельца не совпадает с текущими держателями NFT, стейкер блокирует отправку стейка пользователя валидатору, и средства остаются на контракте до вывода. Эта процедура проверки выполняется каждый раз, когда пользователь отправляет стейк.\
Данные страницы индексируются собственным индексером с использованием API v4.

### Как работает индексер

Для индексеров NFT представляет собой сущность, реализующую открытый [стандарт TON NFT](https://github.com/ton-blockchain/TEPs/blob/master/text/0062-nft-standard.md). Стандарт — это документ, который определяет методы, обязательные для NFT, включая формат возвращаемых и принимаемых данных. Если объект реализует эти методы, он классифицируется как NFT. По сути, NFT может представлять любую сущность, в которой есть такие методы.\
У каждого NFT есть владелец — адрес, записанный в поле владельца контракта NFT. При передаче NFT это поле в контракте меняется без фактического перемещения актива. Для смены владельца используется метод `Transfer`. Текущий владелец должен отправить транзакцию со своего адреса с payload, содержащим команду `Transfer` и адрес нового владельца. Такие транзакции обычно формируются автоматически через [TON Connect](https://docs.ton.org/ecosystem/ton-connect/overview) при передаче NFT, например через платформу [Getgems.io](http://Getgems.io).\
Индексеры анализируют все транзакции блокчейна, чтобы обнаруживать создание новых NFT. При обнаружении соответствующей транзакции система проверяет хэш-код получателя и сравнивает его с известными хэш-кодами NFT, чтобы определить принадлежность к коллекции. Поскольку большинство NFT стандартные, их хэш-коды обычно известны. Индексеры вызывают get-метод `getnftdata`, который возвращает индекс NFT, адрес коллекции и владельца. Полученные данные сохраняются в базе данных для дальнейшего использования.

### Что произойдет, если переместить NFT с кошелька с активным стейком

Если стейк уже отправлен электоратору, он останется там и продолжит участвовать в стейкинге до вывода средств. Однако при повторных депозитах стейкер не отправит средства после проверки наличия NFT, даже если у пользователя уже есть некоторая сумма в стейкинге. Эта сумма останется в статусе pending и будет ждать появления NFT или вывода средств.

<Info>
  Обратите внимание: при выставлении NFT на продажу адрес владельца меняется на адрес маркетплейса, что для стейкера означает фактическое отсутствие NFT в кошельке. Поэтому даже если NFT принадлежит кошельку, но выставлен на продажу, стейкер не пропустит его стейк к электоратору.
</Info>

## Как работает проверка рейтинга

Автоматизация обновления рейтинга в клубном топе не реализована. Проверка адресов происходит через таблицу в сервисе Airtable, куда вручную вносятся адреса кошельков 15 участников клуба с наивысшим рейтингом и членов команды.\
При отправке средств пользователя электоратору стейкер делает запрос к таблице. Он проверяет, содержится ли в ней адрес кошелька пользователя, который пытается отправить средства в пул. Если адрес найден, средства отправляются электоратору. Если соответствующей записи нет, сумма остается в статусе pending и ожидает появления записи или вывода.

### Как рассчитывается рейтинг

Рейтинг пользователя — это сумма рейтингов всех его whales и бонус за заполнение профиля в Whales Club. Подробнее о формировании рейтинга можно прочитать в соответствующем документе. Рейтинг всех пользователей отображается на [странице топ-15 клуба](https://tonwhales.com/club/members).

### Добавление адреса в Team Pool

1. Пользователь обращается в поддержку с просьбой добавить его адрес в командный пул.
2. Оператор поддержки проверяет рейтинг пользователя и сравнивает его с рейтингами участников из топ-15.
3. Если пользователь соответствует критериям топ-15, оператор обновляет список: удаляет адрес участника, который выбыл из топ-15, и добавляет адрес нового участника.
4. Изменения обычно вступают в силу в течение одного часа. Оператор сообщает клиенту об этом временном интервале.
5. После внесения изменений клиент получает возможность отправлять средства в пул.

<Info>
  **Важно.** При первом внесении средств в пул через интерфейс Tonhub или сайт [tonwhales.com](http://tonwhales.com) пользователь увидит предупреждение о необходимости убедиться, что его адрес добавлен в пул. Это предупреждение отображается вне зависимости от фактического наличия адреса в таблице и носит исключительно информационный характер.
</Info>

# Комиссии за стейкинг

Комиссии из партнерских пулов выводятся на кошельки, указанные в DAO этих пулов, либо переводятся ежемесячно, как в случае с P2P. Комиссии из собственных пулов остаются на контроллере.

# Сравнение пулов

На сайте [tonwhales.com](http://tonwhales.com) есть [калькулятор доходности](https://tonwhales.com/staking/compare), который позволяет сравнивать пулы между собой и рассчитывать потенциальную прибыль в пулах по заданной сумме стейка. Пользователь может ввести сумму, которую хочет отправить в стейкинг, а также при желании указать доходность и курс TON. [Калькулятор](https://tonwhales.com/staking/compare) покажет, какую сумму пользователь получит при стейкинге в каждом из пулов.
