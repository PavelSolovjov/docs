---
title: "Высокий приоритет (P1)"
---

| Пробел | Последствие | Решение |
| :-- | :-- | :-- |
| Нет credit notes | Исправления после оплаты <br />требуют `void` \+ повторного invoice | Миграция `039`: <br />таблица `credit_notes` |
| Нет автоматического dunning | Просроченные invoices <br />не помечаются автоматически | Ночной cron: <br />mark overdue \+ email |
| Нет хранения курса USDC | Выручка признается <br />без задокументированного курса | Миграции `040–041`: <br />поля для курса |
| Нет retry-job для сбора | Комиссии со статусом `failed` накапливаются | Retry queue через `next_retry_at` \+ <br />`collection_attempts` |
| `billing_mode` не enforced | Режим `invoice` все еще запускает <br />on-chain collection | Gate в `collectCreationFee()` |
| Нет FX rate lock для settlement | Риск дрейфа курса в течение <br />платежного окна | Фиксировать FX при выпуске statement, <br />а не в момент оплаты |
| Нет логики расчета rebate | Rebate tiers спроектированы, <br />но не вычисляются | Реализовать post-settlement <br />rebate job |
