## Inline-код

Чтобы обозначить `слово` или `фразу` как код, заключите их в обратные кавычки, то есть backticks (`).

```
To denote a `word` or `phrase` as code, enclose it in backticks (`).
```

## Блоки кода

Используйте [fenced code blocks](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks): обрамляйте код тремя backticks и указывайте язык после открывающих backticks, чтобы получить подсветку синтаксиса. При желании можно также добавить имя файла или фрагмента после языка.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
