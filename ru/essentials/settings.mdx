Каждому сайту на Mintlify нужен файл `docs.json` с базовыми настройками конфигурации. Ниже можно посмотреть подробнее про [properties](#properties).

## Properties

<ResponseField name="name" type="string" required>
  Название вашего проекта. Используется как глобальный заголовок.

  Пример: `mintlify`
</ResponseField>

<ResponseField name="navigation" type="Navigation[]" required>
  Массив групп со всеми страницами внутри каждой группы

  <Expandable title="Navigation">
    <ResponseField name="group" type="string">
      Название группы.

      Пример: `Settings`
    </ResponseField>
    <ResponseField name="pages" type="string[]">
      Относительные пути к markdown-файлам, которые будут использоваться как страницы.

      Пример: `["customization", "page"]`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="logo" type="string or object">
  Путь к логотипу или объект с путями к логотипам для `light` и `dark` режима

  <Expandable title="Logo">
    <ResponseField name="light" type="string">
      Путь к логотипу для светлой темы
    </ResponseField>
    <ResponseField name="dark" type="string">
      Путь к логотипу для темной темы
    </ResponseField>
    <ResponseField name="href" type="string" default="/">
      Куда ведет клик по логотипу
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="favicon" type="string">
  Путь к favicon
</ResponseField>

<ResponseField name="colors" type="Colors">
  HEX-коды цветов для глобальной темы

  <Expandable title="Colors">
    <ResponseField name="primary" type="string" required>
      Основной цвет. Чаще всего используется для выделенного контента, заголовков разделов и акцентов в светлой теме.
    </ResponseField>
    <ResponseField name="light" type="string">
      Основной цвет для темной темы. Используется для выделенного контента, заголовков разделов и акцентов в dark mode.
    </ResponseField>
    <ResponseField name="dark" type="string">
      Основной цвет для важных кнопок
    </ResponseField>
    <ResponseField name="background" type="object">
      Цвет фона в светлой и темной теме

      <Expandable title="Object">
        <ResponseField name="light" type="string" required>
          HEX-код цвета фона в светлой теме
        </ResponseField>
        <ResponseField name="dark" type="string" required>
          HEX-код цвета фона в темной теме
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarLinks" type="TopbarLink[]">
  Массив ссылок с полями `name` и `url`, которые вы хотите вывести в topbar

  <Expandable title="TopbarLink">
    <ResponseField name="name" type="string">
      Название кнопки.

      Пример: `Contact us`
    </ResponseField>
    <ResponseField name="url" type="string">
      URL, который откроется по нажатию на кнопку. Пример: `https://mintlify.com/docs`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarCtaButton" type="Call to Action">
  <Expandable title="Topbar Call to Action">
    <ResponseField name="type" type={'"link" or "github"'} default="link">
      `link` показывает обычную кнопку. `github` показывает информацию о репозитории по указанному URL, включая число звезд GitHub.
    </ResponseField>
    <ResponseField name="url" type="string">
      Если `link`: куда ведет кнопка.

      Если `github`: ссылка на репозиторий, из которого нужно подгрузить GitHub-данные.
    </ResponseField>
    <ResponseField name="name" type="string">
      Текст внутри кнопки. Нужен только если `type = "link"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="versions" type="string[]">
  Массив названий версий. Используйте это только если хотите показывать разные версии документации через dropdown в navigation bar.
</ResponseField>

<ResponseField name="anchors" type="Anchor[]">
  Массив anchors, включает `icon`, `color` и `url`.

  <Expandable title="Anchor">
    <ResponseField name="icon" type="string">
      [Font Awesome](https://fontawesome.com/search?q=heart) иконка, которая будет использоваться для anchor.

      Example: `comments`
    </ResponseField>
    <ResponseField name="name" type="string">
      Название подписи anchor.

      Example: `Community`
    </ResponseField>
    <ResponseField name="url" type="string">
      Начало URL, которое определяет, какие страницы попадают в anchor. Обычно это имя папки, в которой лежат страницы.
    </ResponseField>
    <ResponseField name="color" type="string">
      HEX-цвет фона иконки anchor. Также можно передать gradient через объект с полями `from` и `to`, где оба значения - это HEX-цвета.
    </ResponseField>
    <ResponseField name="version" type="string">
      Используется, если вы хотите скрывать anchor до выбора нужной версии документации.
    </ResponseField>
    <ResponseField name="isDefaultHidden" type="boolean" default="false">
      Передайте `true`, если хотите скрыть anchor до тех пор, пока кто-то не перейдет по прямой ссылке на документацию внутри него.
    </ResponseField>
    <ResponseField name="iconType" type="string" default="duotone">
      Одно из значений: `brands`, `duotone`, `light`, `sharp-solid`, `solid` или `thin`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topAnchor" type="Object">
  Позволяет переопределить настройки верхнего anchor по умолчанию.

  <Expandable title="Object">
    <ResponseField name="name" type="string" default="Documentation">
      Название верхнего anchor
    </ResponseField>
    <ResponseField name="icon" type="string" default="book-open">
      Иконка Font Awesome.
    </ResponseField>
    <ResponseField name="iconType" type="string" default="duotone">
      Одно из значений: `brands`, `duotone`, `light`, `sharp-solid`, `solid` или `thin`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tabs" type="Tabs[]">
  Массив навигационных вкладок.

  <Expandable title="Tabs">
    <ResponseField name="name" type="string">
      Название вкладки.
    </ResponseField>
    <ResponseField name="url" type="string">
      Начало URL, которое определяет, какие страницы попадают во вкладку. Обычно это имя папки, в которой лежат страницы.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api" type="API">
  Настройки API. Подробнее про API-страницы см. в разделе [API Components](/api-playground/demo).

  <Expandable title="API">
    <ResponseField name="baseUrl" type="string">
      Базовый URL для всех API-эндпоинтов. Если `baseUrl` передан как массив, пользователь сможет переключаться между несколькими вариантами base URL.
    </ResponseField>
    <ResponseField name="auth" type="Auth">
      <Expandable title="Auth">
        <ResponseField name="method" type='"bearer" | "basic" | "key"'>
          Стратегия аутентификации, используемая для всех API-эндпоинтов.
        </ResponseField>
        <ResponseField name="name" type="string">
          Имя параметра аутентификации, используемого в API playground.

          Если используется метод `basic`, формат должен быть `[usernameName]:[passwordName]`
        </ResponseField>
        <ResponseField name="inputPrefix" type="string">
          Значение по умолчанию, которое будет использоваться как префикс в поле ввода аутентификации.

          Например, если `inputPrefix = "AuthKey"`, то поле аутентификации будет по умолчанию начинаться с `AuthKey`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="playground" type="Playground">
      Настройки API playground

      <Expandable title="Playground">
        <ResponseField name="mode" type='"show" | "simple" | "hide"' default="show">
          Определяет, будет ли playground показан, скрыт или только отображать endpoint без пользовательского взаимодействия, режим `simple`.

          Подробнее см. в [гайдах по playground](/api-playground/demo)
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="maintainOrder" type="boolean">
      Включение этого флага гарантирует, что порядок ключей на OpenAPI-страницах будет соответствовать порядку ключей в самом OpenAPI-файле.

      <Warning>
        Скоро это поведение будет включено по умолчанию, после чего это поле станет deprecated.
      </Warning>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="openapi" type="string | string[]">
  A string or an array of strings of URL(s) or relative path(s) pointing to your OpenAPI file.

  Examples:

  <CodeGroup>

  ```json Absolute
  "openapi": "https://example.com/openapi.json"
  ```

  
  ```json Relative
  "openapi": "/openapi.json"
  ```

  
  ```json Multiple
  "openapi": ["https://example.com/openapi1.json", "/openapi2.json", "/openapi3.json"]
  ```

  </CodeGroup>
</ResponseField>

<ResponseField name="footerSocials" type="FooterSocials">
  An object of social media accounts where the key:property pair represents the social media platform and the account url.

  Example:

  ```json
  {
    "x": "https://x.com/mintlify",
    "website": "https://mintlify.com"
  }
  ```

  <Expandable title="FooterSocials">
    <ResponseField name="[key]" type="string">
      One of the following values `website`, `facebook`, `x`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`

      Example: `x`
    </ResponseField>
    <ResponseField name="property" type="string">
      The URL to the social platform.

      Example: `https://x.com/mintlify`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feedback" type="Feedback">
  Configurations to enable feedback buttons

  <Expandable title="Feedback">
    <ResponseField name="suggestEdit" type="boolean" default="false">
      Enables a button to allow users to suggest edits via pull requests
    </ResponseField>
    <ResponseField name="raiseIssue" type="boolean" default="false">
      Enables a button to allow users to raise an issue about the documentation
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeToggle" type="ModeToggle">
  Customize the dark mode toggle.

  <Expandable title="ModeToggle">
    <ResponseField name="default" type={'"light" or "dark"'}>
      Set if you always want to show light or dark mode for new users. When not set, we default to the same mode as the user's operating system.
    </ResponseField>
    <ResponseField name="isHidden" type="boolean" default="false">
      Set to true to hide the dark/light mode toggle. You can combine `isHidden` with `default` to force your docs to only use light or dark mode. For example:

      <CodeGroup>

      ```json Only Dark Mode
      "modeToggle": {
        "default": "dark",
        "isHidden": true
      }
      ```

      
      ```json Only Light Mode
      "modeToggle": {
        "default": "light",
        "isHidden": true
      }
      ```

      </CodeGroup>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="backgroundImage" type="string">
  A background image to be displayed behind every page. See example with [Infisical](https://infisical.com/docs) and [FRPC](https://frpc.io).
</ResponseField>
