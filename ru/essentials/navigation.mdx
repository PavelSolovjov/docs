Меню навигации - это список ссылок, который отображается на сайте.

Скорее всего, вам придется обновлять `docs.json` каждый раз, когда вы добавляете новую страницу. Страницы не появляются автоматически.

## Синтаксис navigation

Синтаксис navigation рекурсивный, а значит вы можете создавать вложенные группы навигации. Указывать `.mdx` в названиях страниц не нужно.

<CodeGroup>

```json Обычная навигация
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```


```json Вложенная навигация
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": [
            "quickstart",
            {
              "group": "Nested Reference Pages",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## Папки

Просто размещайте ваши MDX-файлы в папках и обновляйте пути в `docs.json`.

Например, чтобы получить страницу по адресу `https://yoursite.com/your-folder/your-page`, нужно создать папку `your-folder` и поместить в нее файл `your-page.mdx`.

<Warning>
  Вы не можете использовать `api` как имя папки, если только она не вложена в другую папку. Mintlify использует Next.js, а он резервирует верхнеуровневую папку `api` для внутренних server calls. Например, имя папки `api-reference` будет допустимым.
</Warning>

```json Навигация с папкой
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Group Name",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## Скрытые страницы

MDX-файлы, не включенные в `docs.json`, не появятся в sidebar, но останутся доступны через поиск и по прямой ссылке.
