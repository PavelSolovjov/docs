## Создание собственного snippet

**Предусловие**: файл snippet должен находиться в директории `snippets`.

<Note>
  Любая страница в директории `snippets` будет восприниматься как snippet и не
  будет рендериться как самостоятельная страница. Если вам нужна отдельная
  страница на основе snippet, импортируйте snippet в другой файл и вызовите его
  как компонент.
</Note>

### Default export

1. Добавьте в файл snippet контент, который хотите переиспользовать в нескольких
   местах. При необходимости можно добавить переменные, которые будут
   заполняться через props при импорте snippet.

```mdx snippets/my-snippet.mdx
Hello world! This is my content I want to reuse across pages. My keyword of the
day is {word}.
```

<Warning>
  Контент, который вы хотите переиспользовать, должен находиться внутри
  директории `snippets`, иначе импорт не сработает.
</Warning>

2. Импортируйте snippet в целевой файл.

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import MySnippet from '/snippets/path/to/my-snippet.mdx';

## Header

Lorem impsum dolor sit amet.

<MySnippet word="bananas" />
```

### Переиспользуемые переменные

1. Экспортируйте переменную из файла snippet:

```mdx snippets/path/to/custom-variables.mdx
export const myName = 'my name';

export const myObject = { fruit: 'strawberries' };
```

2. Импортируйте snippet в целевой файл и используйте переменную:

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { myName, myObject } from '/snippets/path/to/custom-variables.mdx';

Hello, my name is {myName} and I like {myObject.fruit}.
```

### Переиспользуемые компоненты

1. Внутри файла snippet создайте компонент, который принимает props. Для этого
   экспортируйте компонент как arrow function.

```mdx snippets/custom-component.mdx
export const MyComponent = ({ title }) => (
  <div>
    <h1>{title}</h1>
    <p>... snippet content ...</p>
  </div>
);
```

<Warning>
  MDX не компилируется внутри тела arrow function. По возможности используйте
  HTML-синтаксис или применяйте default export, если вам нужен именно MDX.
</Warning>

2. Импортируйте snippet в целевой файл и передайте props

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { MyComponent } from '/snippets/custom-component.mdx';

Lorem ipsum dolor sit amet.

<MyComponent title={'Custom title'} />
```
