## Изображения

### Использование Markdown

С помощью [синтаксиса markdown](https://www.markdownguide.org/basic-syntax/#images) вы можете добавлять изображения следующим образом:

```md
![title](/path/image.jpg)
```

Обратите внимание: размер файла изображения должен быть меньше 5MB. Иначе лучше хранить изображение на сервисе вроде [Cloudinary](https://cloudinary.com/) или [S3](https://aws.amazon.com/s3/), а затем использовать этот URL для вставки.

### Использование embeds

Если вам нужна более гибкая настройка отображения изображения, можно использовать [embeds](/writing-content/embed):

```html
<img height="200" src="/path/image.jpg" />
```

### iFrames

Загружает другую HTML-страницу прямо внутри документа. Чаще всего используется для встраивания видео.

```html
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
