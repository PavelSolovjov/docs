**Количество выпущенных NFT:** 2,652\

# Смарт-контракт минта

Этот смарт-контракт позволяет пользователям получать, то есть mint, NFT со случайными атрибутами, отправляя средства на его адрес. При mint адрес пользователя становится owner-адресом NFT. Пользователь может mint-ить один или несколько item, а количество рассчитывается на основе отправленной суммы.\
Ключевая особенность смарт-контракта минта — динамическое ценообразование с постоянным ростом цены токена. Цена росла по алгоритму, показанному в таблице ниже. Размер шага уменьшался пропорционально текущей цене, что давало быстрый рост цены на раннем этапе и более медленное увеличение позже.\
Пример: первый whale в коллекции стоил 100 TON, следующий — 100.6 TON и так далее. Когда цена whale доходила до 399 TON, шаг уменьшался с 0.6 до 0.05 TON.

1. Контракт минта коллекции

## Контракт минта коллекции

Позволяет создавать коллекцию с заданными параметрами.\
**Ссылка:** https://github.com/tonwhales/nft-minter\
**Язык:** TypeScript

### Основные операции

Если `sender_address == ctx_owner`, то используется **административный обработчик** `op_owner`:

- `op::update` — изменить параметры:
  - `ctx_sale_opened`, `ctx_total_supply`, `ctx_mint_limit`, `ctx_price`, `ctx_step`, с проверками лимитов и минимальной цены.
- `op::close` — закрыть продажу, то есть `sale_opened=false`, `mintLimit=minted`.
- `op::open` — открыть или расширить продажу, добавить `+count` к `mintLimit`, задать новый `step`, установить `sale_opened=true`.
- `op::upgrade` — обновить код, записать новый `code`.
- `op::purchase` — выполнить mint от имени owner, дальше управление переходит в `op_purchase`, флаг показывает, что buyer — это owner.
- `op::topup` — просто принять средства, без дополнительной логики.
- `op::update_content` — обновить `content`, то есть URI.
- `op::transfer_ownership` — сменить `owner`.
- `op::update_royalty_params` — обновить royalty.
- `op == 0` + текст `"NFT"` — mint одного NFT, текстовая форма.

Публичные операции, если вызов идет не от owner:

- `op == 0` и строка `"NFT"` → одиночный mint, то есть `op_purchase(sender, ..., count=1)`.
- `op::purchase` → mint `count` NFT (`op_purchase(sender, ..., count)`).

### Как запустить mint

1. Сгенерируйте BOC:

- Через скрипт `bash`, который выведет `Open:` \<base64 BOC\>.

```
yarn ts-node manage/mainnet/open.ts
```

В результате он выведет `Open:` \<base64 BOC\>.

- либо программно вызвать `createOpenMessage(count, step)`.
2. Отправьте внутреннее сообщение:


- recipient — адрес collection,
- sender — кошелек `owner`,
- body — этот BOC,
- value — небольшой резерв на комиссию, например 0.1–0.2 TON, в зависимости от сети.

После этого:

- `sale_opened = true`,
- `mintLimit` увеличивается,
- mint через `purchase` или `"NFT"` становится доступным в рамках нового лимита.

### Как остановить mint

1. Сгенерируйте BOC: `createCloseMessage().toBoc().toString('base64')`, либо запустите `close.ts`.
2. Отправьте внутреннее сообщение:
   1. на адрес collection,
   2. **из owner wallet**,
   3. с `body = this BOC`,
   4. и небольшим количеством TON для gas.

После этого mint останавливается.

### Как обновить royalty коллекции

- `factor / base` = доля royalty, например `5 / 100 = 5%`,
- `address` — адрес, на который отправляются royalties.

```
ts
Copy
import { Address } from 'ton';
import { updateRoyaltyParams } from './src/collection-minter';

const factor = 5;
const base = 100;
const royaltyAddress = Address.parse('...');

const body = updateRoyaltyParams(factor, base, royaltyAddress);
const boc = body.toBoc().toString('base64');

// после этого отправьте internal-message на адрес коллекции с этим body
```

### Как сменить owner коллекции

Работает только если **sender = текущий owner**.

1. В `manage/mainnet/transfer-ownership.ts`:
   1. в `Address.parse('')` укажите адрес нового owner в friendly-формате.
2. Запустите скрипт:

```
yarn ts-node manage/mainnet/transfer-ownership.ts
```

3. Скрипт выведет ссылку вида:

```
Transfer ownership: https://tonhub.com/transfer/EQ...NFT?amount=...&bin=...
```

а также QR-код.

4. Откройте эту ссылку через **кошелек текущего owner**, то есть тот, который записан в `owner` или `ctx_owner`, и подтвердите транзакцию.

## Контракт минта отдельного item

Позволяет owner указать адрес кошелька покупателя для конкретного item в коллекции.\
**Ссылка:** https://github.com/tonwhales/nft-contract\
**Язык:** Solidity

### Основные операции

`op_transfer(slice cs)` — transfer уже существующего token.\
`op_award(slice cs)` — распределение **uninitialized** NFT, то есть airdrop, на конкретный адрес.\
`op_update_metadata(slice cs)` — обновление **общих metadata коллекции**.\
`op_mint(slice cs)` — mint нового token по текущим настройкам mint.\
`op_ping(slice cs)` — проверяет, что контракт активен и вы являетесь owner.\
`op_upgrade(slice cs)` — обновление кода контракта.

## Кошельки для сбора средств

Изначально выручка от продаж отправлялась на один кошелек, который позже был заменен другим. Сейчас все royalties со secondary market отправляются на новый NFT treasury wallet.

## Вторичный рынок

Компания получает royalties от продажи whales на secondary market. Royalties составляют 5% от каждой продажи whale и могут быть изменены owner коллекции. Дополнительно еще 5% от продажи уходит marketplace, на котором происходит сделка, и эта доля не изменяется. Все royalties отправляются на тот же кошелек, который получает выручку от mint, и могут быть выведены owner этого кошелька.

# Telegram Club Bot

Любой владелец NFT whale получает доступ в приватный чат Ton Whales в Telegram. В чате пользователи могут общаться с CEO компании, заводить новые знакомства и узнавать новости. Доступ к чату предоставляется через бота \
https://t.me/whalesclub_bot\
Бот работает в inline-режиме и может быть вызван из любого чата.

## Инструкция по входу в чат

1. Перейдите в бот https://t.me/whalesclub_bot
2. Выберите способ верификации
   1. Через Tonhub, этот способ позволяет отсканировать QR-код приложением кошелька, в котором открыт адрес с NFT whale.
   2. Через другой кошелек, этот способ позволяет отправить минимальную транзакцию на адрес, указанный ботом, с адреса, на котором находится NFT whale.
3. В ответном сообщении бот пришлет ссылки для входа в приватные чаты.

## Как бот проверяет владение NFT

Бот является администратором и каждые два часа проверяет у всех участников чата наличие NFT-токенов в кошельках, бот обращается к той же странице, что и стейкер. Если соответствующего NFT нет, участник автоматически удаляется из чата.\
Важно учитывать, что бот не отслеживает перевод NFT на адреса sale contracts, поэтому пользователи, выставившие NFT на продажу, но не завершившие сделку, сохраняют доступ к чату.

## Кнопки и команды бота

- `My profile` — позволяет заполнить форму для handshake system.
- `Whales club staking pools` — перенаправляет пользователя на страницу стейкинга.
- `Show my whales` — генерирует GIF со всеми whales пользователя.
- `Set the club status` — позволяет отправить заявку на club status.
- `Join the club` — генерирует ссылки для входа в приватные чаты клуба.
- `Members projects section` — позволяет отправить заявку на публикацию проекта в разделе проектов на сайте.
- `Accelerator program` — отправка заявки в программу поддержки проектов.
- `My wallets` — позволяет добавить несколько кошельков и объединить их в один профиль.
- `/mywhales` — команда, которая позволяет делиться GIF со всеми whales участника клуба в любом чате.

### Дополнительные возможности

- Каждый новый заполненный профиль из handshake system автоматически публикуется ботом в клубных чатах.
- Каждый новый проект, опубликованный участниками на project board, автоматически публикуется ботом в клубных чатах.
- Каждая продажа NFT whale на secondary market автоматически публикуется ботом в клубных чатах с указанием цены.

# Handshake system

Handshake system позволяет анонимно знакомить участников клуба между собой. Пользователь создает профиль в клубном боте, указывая свою сферу деятельности и краткое описание того, чем он занимается. Профиль публикуется на странице:

- https://tonwhales.com/club/members

Другие пользователи могут отправить owner профиля handshake, то есть выразить интерес, приложив короткое сообщение. Получатель handshake получает уведомление через бота и может посмотреть профиль отправителя. Пользователь может принять предложение познакомиться, проигнорировать его или отклонить. При принятии участники получают доступ к Telegram usernames друг друга.\
Функцию получения handshake пользователь может отключить в настройках club bot. Когда эта опция деактивирована, кнопка отправки handshake в профиле пользователя становится недоступной.

<Info>
  Handshake system не работает для пользователей без заданного username в Telegram. В таком случае бот возвращает сообщение об ошибке.
</Info>

Мониторинг отправленных handshakes и управление лимитами на их отправку выполняются через соответствующий раздел NFT admin panel.

# Статусы клуба

Чтобы упростить адаптацию новых участников в клубных чатах, была внедрена система статусов. Статус отображается справа от имени пользователя и содержит информацию, которая помогает быстрее и точнее идентифицировать участника. По сути, статус — это admin role с отключенными дополнительными привилегиями.

<Info>
  Важно учитывать, что количество администраторов в Telegram-чате ограничено 50 пользователями, поэтому и была внедрена система проверки статусов.
</Info>

## Как установить статус

1. Пользователь переходит в club bot, в раздел `Set the club status`.
2. Указывает статус, который хочет видеть в своем чат-профиле.
3. Запрос на смену статуса отправляется в NFT admin panel.
4. Администратор может одобрить или отклонить запрос, если статус не дает полезной информации другим пользователям.

Если пользователь хочет изменить уже полученный статус, он может отправить новый запрос через club bot.

# Индивидуальный рейтинг пользователя

Рейтинг пользователя в клубе — это показатель, который отражает его активность, а также редкость и количество принадлежащих ему NFT whales. Рейтинг показывается на карточке пользователя на странице:

- https://tonwhales.com/club/members

## Для чего нужен рейтинг

1. Рейтинг определяет позицию карточки пользователя на странице участников клуба: участники с более высоким рейтингом попадают выше в общем списке. Профили пользователей с высоким рейтингом получают больше внимания, а значит и лучшие возможности для нетворкинга.
2. Участники из топ-15 по рейтингу получают эксклюзивный доступ к размещению средств в самом выгодном staking pool Ton Whales — Team Pool.

## Как формируется рейтинг

Рейтинг состоит из двух основных частей:

- rarity score их NFT whales
- бонус за заполнение профиля

## Rarity score whales

Это сумма rarity scores всех whales пользователя. Каждый whale получает разное количество баллов в зависимости от редкости его атрибутов, например cigars, flags, toys и так далее. Rarity score конкретного whale можно посмотреть [на preview page](https://tonwhales.com/club/preview), введя его rank.

### Whale health system

Чтобы мотивировать пользователей снимать whales с продажи и держать их дольше, была внедрена whale health system. Эта система влияет на rarity score whale, если он был выставлен на продажу.\
**Параметры health system:**\
NFT token сейчас находится в активной продаже — 0% базового рейтинга\
NFT token снят с продажи меньше месяца назад — 50% базового рейтинга\
NFT token снят с продажи меньше трех месяцев назад — 75% базового рейтинга\
NFT token не выставлялся на продажу 3-6 месяцев — 100% базового рейтинга\
NFT token не выставлялся на продажу 6-12 месяцев — 125% базового рейтинга\
Whale не выставлялся на продажу больше года — 150% рейтинга

### Коллекция mixtures, восстановление health

Если пользователь хочет быстро восстановить rarity score всех своих whales, например чтобы получить доступ к team pool, для этого была выпущена отдельная коллекция — [**Whales' mixtures**](https://getgems.io/collection/EQBfzg4YVfjikDozTkMR1xHGWeyLRsfvgHWL6SoUfzmW5j4B#activity). Использование такой mixture мгновенно восстанавливает rarity score всех whales пользователя до 100%.\
Чтобы использовать mixture, пользователь должен перевести ее на [NFT treasury wallet](https://tonwhales.com/explorer/address/EQBgxXRsXrDbcYuHD6Gn9dzv5FCE-FdsJqqI2QfqpfwxCNGZ) и уведомить об этом project manager или community manager. Менеджер заходит в административную панель и вручную выставляет health indicator каждого whale пользователя на 100%, что сразу улучшает его позицию в rating table.\
Сейчас mixtures доступны для покупки только на secondary market.
