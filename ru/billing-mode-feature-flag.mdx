---
title: "Фича-флаг billing mode"
---

`billing_mode` в `instances.settings`, это feature flag:

| Режим | Описание | Статус |
| :-- | :-- | :-- |
| `on_chain` | Комиссии автоматически собираются по каждому чеку через SPL delegate | Реализовано |
| `invoice` | Комиссии накапливаются, инвойсятся ежемесячно и собираются off-chain | Подготовлено, но еще не enforced |
| `hybrid` | Для creation используется on-chain, для остальных комиссий invoice | Запланировано |

Когда `billing_mode = 'invoice'`, функция `collectCreationFee()` должна пропускать on-chain перевод и вместо этого устанавливать `collection_status = 'invoiced'`. После этого комиссия попадает в ежемесячный invoice как отдельная строка для off-chain сбора. Сейчас этот gate еще не реализован.
