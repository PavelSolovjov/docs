---
title: "Methods for confirming online transactions"
---

1. The user initiates payment by entering the card number, expiration date, and CVV code on the website.
2. The user pre-selects the confirmation method: in the app or by text message.

3. The system prompts the user to confirm the operation using a code sent to their phone number if code confirmation is selected, or to go to the application if banner confirmation is selected.
4. Upon user consent, confirmation is carried out using the method previously selected in the application. Banner:

5. After receiving the six-digit code, the user enters it in the confirmation system interface.
6. The system requests the 3DS password, which is displayed on the card page in the application. The user enters this password in the system interface.
7. After successful verification, the system processes the charge.
