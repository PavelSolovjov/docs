# App Installation

The Tonhub application can be downloaded from the following official sources:

- [App Store](https://apps.apple.com/us/app/tonhub-crypto-wallet-card/id1607656232) — for installation on devices with iOS operating system.
- [Play Store](https://play.google.com/store/apps/details?id=com.tonhub.wallet&hl=en) — for installation on devices with Android operating system.
- [Wallet Repository](https://github.com/tonwhales/wallet/releases) — for downloading installation files on devices that do not support the app stores mentioned above. Files are updated manually by developers.

<Info>
  **Warning:** Download the application exclusively from official sources. Installing from unofficial sources creates serious security risks and may lead to compromise of your cryptocurrency assets.
</Info>

# Creating/importing a new wallet

1. After installing the application, open it on your device and select one of two options:

- Create a new wallet — covered in this section.
- Import an existing one — read about integrating an existing wallet below.

2. Accept the privacy policy terms and click "Continue". This step is not present when adding a second or subsequent wallet to the application.
3. Write down the seed phrase and store it in a secure location. Taking screenshots is not recommended for security reasons.

# Importing an Existing Wallet

1. You can add an existing wallet to the application either immediately after installation (see step 1 of creating a new wallet) or by tapping on the wallet name in the upper left corner of the screen and selecting the option to add an existing wallet.
2. After selecting the corresponding option, the application will open a form for entering the seed phrase. Enter the secret phrase words in the corresponding fields. The application will suggest variants of the word being typed in the field above the keyboard. If a word is entered incorrectly, the application will highlight the corresponding field. You can also paste the entire secret phrase into the first word field (all words in the first field separated by single spaces, without commas or extra characters) if it's in the clipboard, however storing keys in the clipboard may be unsafe.
3. After confirmation, you will proceed to the main screen of the added wallet.

# Adding Ledger

A Ledger hardware wallet can be added as the first or additional wallet.

1. Tap on the wallet name in the upper left corner of the screen and select the "Connect Ledger" option.
2. Choose the connection method. When using iOS, the only available connection method is Bluetooth, while Android also supports wired connection.
3. Grant Ledger the requested permissions — connection is impossible without them.
4. After the search is complete, select your device from the list of found devices.

# What to do if the seed phrase doesn't work

If the wallet reports an input error after entering the seed phrase, it is recommended to perform the following actions:

1. Check the correct order of words. Make sure there are no gaps or repetitions.
2. Ensure that all words correspond to the standard English list (BIP-39), contain no typos, and are not translated into other languages.
3. Make sure the phrase contains exactly 24 words — Tonhub supports this format specifically.
4. Ensure that you are entering a seed phrase from a wallet on the TON or Solana network. When entering a phrase from a wallet on a blockchain not supported by Tonhub, the wallet will not open or display assets.

<Info>
  **Important:** The seed phrase format may vary depending on the application. This most commonly affects wallets in the Solana blockchain. If you are confident that your seed phrase is correct but Tonhub does not accept it, try entering it in the wallet that was used to create it. If the wallet opens, this means that the phrase encoding is not supported by Tonhub.
</Info>

# Wallet Deletion/Logout

A wallet in the blockchain cannot be deleted, but it can be made inactive or logged out of.

- Wallet logout - the wallet remains active but is no longer displayed in the application. To perform operations with it, you will need to log in again using the seed.
- Wallet deletion - as required by Apple, the application must have the ability to delete a wallet. In fact, the wallet receives inactive status, but access and the possibility of reactivation are preserved.

## Wallet Deletion

1. Go to the settings section, find the "Delete Wallet" option and click on it.
2. Enter the address where the assets will be transferred (by default, the Whales CORP address is set). Deletion will be blocked if there are NFTs or USDT in the wallet — you will first be prompted to withdraw them. The wallet must also have sufficient funds to pay the withdrawal fee.

# Wallet Versions

The Tonhub application works exclusively with wallet versions 4 and above. When importing wallets of earlier versions, they are not displayed in the application interface. However, the system automatically checks such wallets for the presence of TON and, upon detection, offers the user to migrate assets to a supported version.\
The key difference between versions 4 and 5 lies in the support for gasless transactions in the fifth version. This feature allows paying transaction fees in the currency of the token being sent, rather than only in TON.

## Address Formats

Tonhub uses two main address formats:

- **EQ… — bounceable address.**
- **UQ… — non-bounceable address.**

The UQ format provides developers with the ability to distinguish between contracts and standard wallets. For the end user, this distinction manifests exclusively in the way the address is displayed.\
It is important to understand that the EQ and UQ prefixes are merely different ways of displaying the same address — the internal structure (workchain and address hash) remains identical. In Tonhub settings, you can select the preferred address display format in the "Address Format" section, however this change only affects the visual representation of the address string and does not affect the wallet itself.
