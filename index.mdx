Holders provides an SDK that enables seamless integration of bank card payments with a user's TON or USDC (SOL) wallet via a smart contract deployed on TON or Solana. The smart contract is linked directly to the user's wallet, enabling decentralized control over funds. Currently, Holders is integrated into the [**Tonhub**](https://gettonhub.com/) wallet.\
Alternatively, Holders can be integrated via API instead of the SDK, giving full flexibility to customize and render all interface components independently.

## DApp: Initial State

Inject initial state for authorization and faster app loading.\
Simply add the `initialState` object to the **window** object.

### Types

```
type WindowInitialState = {
  user?: {
    token: UserTokenT;
    status: UserStatusT;
  };
  accountsList?: AccountT[];
  prepaidCards?: CardPrepaidT[];
};
```

### Example

Here's an example of how you can inject the initial state for faster app loading:

```
window.initialState = {
  user: {
    token: "user_token_here",
    status: {
          // User state object
    }
  },
  accountsList: [
    // Array of account objects
  ],
  prepaidCards: [
    // Array of prepaid card objects
  ]
};
```

This code should be placed in your application's entry point. It sets the **initialState** object on the **window**, which can then be accessed by your application to initialize its state more quickly.

# API integration

## Public Accounts list endpoint

We aim to provide a seamless experience for users who have logged into their wallet without obtaining a Holders authentication token.\
**URL:**`https://${endpoint}/v2/public/accounts`

<Card title="Example" icon="arrow-down-right" href="https://github.com/tonwhales/wallet/blob/master/app/engine/api/holders/fetchAccounts.ts" cta="Check">
  
</Card>

```
export async function fetchAccountsPublic({ address, solanaAddress, isTestnet }: { address: string | Address, isTestnet: boolean, solanaAddress?: string }) {
  const endpoint = holdersEndpoint(isTestnet);
  const addressString = (address instanceof Address) ? address.toString({ testOnly: isTestnet }) : address;
  const body = solanaAddress ? {
    walletKind: 'tonhub',
    wallets: [
      {
        network: isTestnet ? 'ton-testnet' : 'ton-mainnet',
        address: addressString
      },
      {
        network: 'solana',
        address: solanaAddress
      }
    ]
  } : {
    walletKind: 'tonhub',
    network: isTestnet ? 'ton-testnet' : 'ton-mainnet',
    address: addressString
  };

  const res = await axios.post(
    `https://${endpoint}/v2/public/accounts`,
    body,
    {
      headers: {
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*",
        "Access-Control-Allow-Headers": "*",
        "Access-Control-Allow-Credentials": "true",
      }
    }
  );

  if (res.status === 401) {
    return null;
  }

  const parseResult = accountsListPublicSchema.safeParse(res.data);
  if (!parseResult.success) {
    console.warn(JSON.stringify(parseResult.error.format()));
    throw Error("Invalid public card list response");
  }

  if (!res.data.ok) {
    throw Error(`Error fetching card list: ${res.data.error}`);
  }

  return res.data.accounts as GeneralHoldersAccount[];
}
```

## Obtaining User Access Token

Enrolling a user involves creating a TON Connect 2.0 injected bridge for the app at the holdersUrl endpoint. This process includes authenticating via the user's private key, saving the TON Connect 2.0 app injected bridge connection, and fetching the private account token.\
You can then use this token to synchronize private account data and transactions, as well as pass it as part of the injected initial state to Holders.\
**URL:**`https://${endpoint}/v2/user/wallet/connect`

<Card title="Example" icon="arrow-down-right" href="https://github.com/tonwhales/wallet/blob/master/app/engine/hooks/holders/useHoldersEnroll.ts" cta="Check">
  
</Card>

```
export async function fetchAccountToken(config: {
    address: string,
    walletConfig: string,
    walletType: string,
    time: number,
    signature: string,
    subkey: {
        domain: string,
        publicKey: string,
        time: number,
        signature: string
    }
}, isTestnet: boolean): Promise<string> {
    let res = await axios.post(
        'https://' + holdersEndpoint +'/v2/user/wallet/connect',
        {
            stack: 'ton',
            network: isTestnet ? 'ton-testnet' : 'ton-mainnet',
            key: {
                kind: 'ton-x-lite',
                config
            }
        }
    );
    if (!res.data.ok) {
        throw Error('Failed to fetch card token');
    }
    return res.data.token as string;
}
```

export async function fetchAccountState(token: string) {
    let res = await axios.post(
        'https://' + holdersEndpoint + '/account/state',
        { token }
    );

    if (res.status === 401) {
        return null;
    }

## OTP notifications

![Flowchart2](/images/Flowchart2.png)

**1. Get OTP Delivery Configuration**\
**URL**

```
POST ${endpoint}/user/otp/delivery/config/get
```

**Description**\
Retrieves the current OTP delivery configuration for the user.\
**availableProperties** - is a set of configurable values. If confirmationTypes contains one type only (for example TEXT_CODE) - it’s not possible to choose between "TEXT_CODE" and "CONFIRMATION_BUTTON" according to the current customer partner/card provider. The same applied to push/email/sms boolean properties.\
\
**Request**

```
{
  "token": "string"
}
```

**Response**\
• **200**

```
{
  "ok": true,
  "data": {
    "currentConfig": {
      "confirmationType": "TEXT_CODE" | "CONFIRMATION_BUTTON",
      "push": true | false,
      "email": true | false,
      "sms": true | false
    },
    "availableProperties": {
      "confirmationTypes": ["TEXT_CODE", "CONFIRMATION_BUTTON"],
      "push": true | false,
      "email": true | false,
      "sms": true | false
    }
  }
}
```

**OR**

```
{
  "ok": false,
  "error": "no_product"
}
```

**Example (Axios)**

```
import axios from 'axios';

export async function getOtpDeliveryConfig(token) {
  const response = await axios.post(`${endpoint}/user/otp/delivery/config/get`, {
    token
  }, {
    headers: { 'Content-Type': 'application/json' }
  });
  return response.data;
}
```

**3. Confirm an OTP Request**\
**URL**

```
POST ${endpoint}/user/otp/requests/confirm
```

**Description**\
Confirms or rejects a pending confirmation request.\
**Request**

```
{
  "token": "string",
  "data": {
    "id": "${txnId}",
    "status": "REJECTED" | "CONFIRMED"
  }
}
```

**Response**\
• **200**

```
{
  "ok": false,
  "error": "not_confirmation_type" | "expired" | "already_rejected" | "already_confirmed" | "disabled_for_provider"
}
```

**OR**

```
{
  "ok": true
}
```

**Example (Axios)**

```
import axios from 'axios';

export async function confirmOtpRequest(token, requestId, status) {
  const response = await axios.post(`${endpoint}/user/otp/requests/confirm`, {
    token,
    data: {
      id: requestId,
      status
    }
  }, {
    headers: { 'Content-Type': 'application/json' }
  });
  return response.data;
}
```
