## Setting up, changing and tracking blockchain limits

1. To set up/change limits, the user clicks on the corresponding card on the account page where they want to set up/change the limit.

   <img
     src="/images/Group1948755865.png"
     alt="Group1948755865"
     title="Group1948755865"
     className="mx-auto"
     style={{ width:"24%" }}
   />
2. The user navigates to the limit type selection page. After that, they enter the values for all necessary limits and confirm saving by clicking the "Save" button.

   <img
     src="/images/IMG_0478(1).PNG"
     alt="IMG 0478(1)"
     title="IMG 0478(1)"
     className="mx-auto"
     style={{ width:"25%" }}
   />
3. The service redirects the user to the wallet application, where it asks them to sign a transaction to set the limits.
4. After signing the transaction, limits are typically set/updated within a few minutes. A loader is displayed at the top of the interface showing whether the transaction has been processed.

   <img
     src="/images/2025-09-2217.46.04.jpg"
     alt="2025 09 2217 46 04"
     title="2025 09 2217 46 04"
     className="mx-auto"
     style={{ width:"27%" }}
   />

   Limit changes are also displayed in the account transaction history.

   <img
     src="/images/2025-09-2217.48.19.jpg"
     alt="2025 09 2217 48 19"
     title="2025 09 2217 48 19"
     className="mx-auto"
     style={{ width:"27%" }}
   />
5. After setting up limits, a card appears on the main account page showing the progress scale of the nearest limit.

   <img
     src="/images/2025-09-2217.52.59.jpg"

## Displaying Issuer Bank Limits

Issuer limits are displayed on the page of each bank card linked to the account. Users can view the remaining balance until each type of limit is reached.
